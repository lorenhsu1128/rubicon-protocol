# RUBICON PROTOCOL — GLB 模型製作規格

遊戲中的每個 3D 模型都有一個「模型槽」。沒有 GLB 的槽位會顯示程式產生的模型（three.js），提供 GLB 後就改用 GLB。
所有規格都可以在**模型庫**（`dist/model-library.html`，伺服器上的 `/models`）逐項檢查。

機甲不是一整個模型，而是由一塊塊**區塊**組成：每個會動的部位都是獨立的 GLB，只含網格與貼圖，**不需要骨架或關節節點**。
區塊之間怎麼接（例如手肘在上臂的哪裡）由遊戲的**連接點**決定。會動的載具（戰車砲塔、直升機旋翼）也一樣拆成區塊。

## 1. 工作流程

1. 打開模型庫，找到要製作的槽位，記下格子下方的**槽位 id**（例如 `arms/a_std/r_fore`）。
2. 在檢視窗按「**下載範本 GLB**」：這是把現有程式模型照本規格匯出的檔案，匯入 Blender 等軟體即可當作比例、原點、朝向與材質命名的參考。
3. 製作完成後匯出 GLB，**拖到模型庫對應的格子上**（或在檢視窗按「載入 GLB…」）。檔案只存在你的瀏覽器裡（IndexedDB），不會上傳，也不會影響其他人。
   AI 生成或其他來源的 GLB 若朝向、尺寸、原點不對，可以在模型庫的「**GLB 編輯**」頁籤修正（見下方「GLB 編輯器」）。
4. 看檢視窗右側的**規格檢查**（✓ 通過、⚠ 警告、✗ 錯誤），並用「並排對照」「疊合對照」「組合預覽」「動作預覽」確認外觀。組合預覽會把這個區塊裝到整台機甲上（其他區塊有 GLB 也會一起用），可以看關節彎曲時有沒有穿幫。
5. **在遊戲裡試玩**：遊戲的「按鍵與操作設定」→「本地模型庫（單人模式）」打勾，單人模式就會換上模型庫存在這個瀏覽器的 GLB 與關節設定（見下方「在遊戲中試用」）。
6. 確定採用後，把檔案放到 `src/assets/models/<槽位 id>.glb`（例如 `src/assets/models/arms/a_std/r_fore.glb`），執行 `npm run build`，GLB 就會內嵌進模型庫（遊戲目前還不讀內建的 GLB）。
7. 模型庫上方的「匯出對照表」可以輸出所有槽位的來源、檔案、目標路徑、尺寸與檢查結果（JSON）。

### 模型組

- 同一個瀏覽器可以存好幾套機甲模型，每一套叫一個**模型組**：機甲區塊（頭、核心、手臂、腳、背包）與武器（手持、背部）的 GLB、關節設定，以及組裝調整頁的零件組合，各模型組一份。載具、地圖物件、小物件不分模型組（所有模型組共用）。
- 模型庫左上角的「**模型組**」選單：點名稱切換；「新增空白」（名稱用上面的欄位，零件組合沿用目前的）；「複製目前」；「改名」；「刪除」（至少保留一組）。
- 拖曳替換、GLB 編輯器存檔與鏡像、拆分存檔、組裝調整的關節與原點，一律存進**目前的模型組**；模型組裡沒有的槽位用內建 GLB 或程式模型。關節設定要配合同一組 GLB 的原點，所以一定整組切換。
- 「**匯出…**」把目前的模型組存成一個 `.rubicon-set` 檔（zip：`manifest.json`、`joints.json`、`models/<槽位 id>.glb`，有原始檔的另存 `orig/`）；「**匯入…**」把檔案加成一個新模型組（同名時自動加編號）。可以用來備份、分享，或在直接開檔與伺服器網址兩種開啟方式之間搬移資料。
- 舊版的瀏覽器暫存會自動歸到「預設」模型組。

### GLB 編輯器

模型庫上方的「GLB 編輯」頁籤（或檢視窗的「在 GLB 編輯器開啟」）可以直接修正 GLB，不必回到建模軟體：

- **目標槽位**：選了槽位才會顯示程式模型（半透明線框）、這個區塊的連接點與原點規格，並即時做規格檢查；不指定槽位時只能下載。
- **朝向**：選「正面是／上方是」後套用，轉成規格的 +Z 正面、+Y 上方；也可以繞 X／Y／Z 轉 ±90°，或「左右翻轉」（例如把左手改成右手）。
- **尺寸**：「對齊程式模型」等比縮放並移到程式模型的外框（外框整體符合／高度相同／最長邊相同；上下以中心、底部或頂部對齊）；或輸入高度、倍率。
- **原點**：底面中心、外框中心、頂面中心，或「點選設定」在模型上點一下（預設取前後表面的中點，點在關節圓柱上就是圓柱中心），或「拖曳原點」用箭頭把橘色把手拖到想要的位置、放開即套用（Esc 結束）。選了槽位時，黃色圓環標出程式模型的原點（例如前臂的手肘轉軸），把 GLB 的關節對準它即可。機甲區塊通常不需要在這裡設定原點：到「組裝調整」頁拖曳關節點即可（見第 3 節）。
- **組合**：「加入 GLB…」把另一個 GLB（例如另外生成的肩甲、配件）加進來成新節點，選取後移動、旋轉、縮放到位置；節點的「合併成一個節點」把它與子節點合成一個（同材質的網格合併）。
- **節點**：左側列出節點，可以選取後單獨移動／旋轉／縮放、改名、隱藏（隱藏的不匯出）或刪除（例如 AI 附帶的底座）。
- 拖曳箭頭（W 移動、E 旋轉、R 縮放）、數值輸入、Ctrl+Z／Ctrl+Y 復原重做、F 重新取景。
- **存檔**：「存到槽位」把變換寫進頂點後存進瀏覽器暫存（第一次存檔時保留原始檔，之後可「還原原始檔」）；「鏡像存到另一側」產生另一側的區塊（例如右前臂 → 左前臂）；「下載 .glb」；「到檢視窗查看」以組合預覽裝到整台機甲上確認。
- **刪除多邊形**（右側「選取多邊形…」，建議在拆分之前先清掉 AI 附帶的底座、漂浮碎片、內部夾層）：
  - 選取方式：矩形、套索（按住拖曳畫出範圍）、筆刷（刷過的面；可調半徑，按住 Ctrl 擦除）、點選相連（點一下選整塊相連的面）。矩形與套索直接拖曳是取代選取，Shift 加選、Ctrl 減選。選到的面以紅色標示。
  - 深度：「只選看得到的」（預設，被擋住的與背面不會選到；比一個像素還小的面可能漏選，再選一次即可）、「只選朝向鏡頭的」（含被擋住的）、「穿透」（範圍內全部）。可勾選「完全在範圍內才選」（三個頂點都在範圍內）。
  - 「擴展到相連」：已選的面所在的整塊；「反選」；「選取小碎塊」：面數少於指定值或面積小於全部的指定百分比的碎塊（最大的一塊不選）。相連以頂點位置判斷（AI 模型的頂點常常沒有焊接）。
  - 「對稱選取」：以原點的 X=0 左右鏡像，另一側對應的面一起選（左右切法不同也能對上）。請先把模型左右置中。
  - 確認後按「刪除選取的面」或 Delete；沒用到的頂點一起清掉，整個網格都刪掉時當成刪除節點。可以復原。選取模式中左鍵選取，右鍵旋轉、中鍵平移、滾輪縮放；Esc 清除選取，再按一次離開。拆分模式中不能使用（改用拆分的「框選」＋「排除」）。
- **材質與換色**（建議在拆分前對整台模型處理）：遊戲依材質名稱換色，AI 生成的模型通常只有一個材質、一張烘焙了所有顏色的貼圖，可以這樣處理：
  - 「依顏色分群」：依貼圖顏色把三角形分成幾群（2～8），每群選一個色槽（主色、副色、關節…或保留原色）後「套用分群」。
  - 「框選改成」：選色槽後按「框選」，在畫面上拖曳框選三角形改用這個色槽（可只選朝向鏡頭的面）。
  - 「色槽的貼圖」：遊戲換色是「陣營色 × 貼圖」，彩色貼圖會變混濁，預設轉成灰階（保留明暗、依該群亮度調整），也可以保留彩色或移除貼圖。
  - 左側「材質」清單可以整個材質改色槽、調粗糙度／金屬感／發光；「合併相同的材質」減少重複材質；「預覽配色」切換陣營配色確認效果。
- **貼圖**（左側材質清單展開材質後，每張貼圖一列；同一張圖用在多個欄位時合成一列，例如「粗糙度／金屬感」）：
  - 「下載」：目前畫面上用的圖（PNG，包含編輯器產生的灰階圖）；「原檔」：GLB 裡原本的圖片檔（原格式與畫質）或換上的圖片檔；「UV」：與貼圖同尺寸的 UV 線框（線條依材質著色，可選疊在貼圖上），拿到繪圖軟體當參考圖層。沒有貼圖的材質也可以下載 UV 線框（1024×1024）。
  - 「下載全部貼圖（.zip）」：`貼圖/`（目前的圖）、`原始檔/`、`UV/` 三個資料夾（後兩者可勾選）。
  - 「替換…」選圖片（PNG／JPG／WebP），或直接把圖片拖到那一列上。換圖範圍：「這張貼圖」（所有共用的材質一起換，色槽材質的灰階圖會依新圖重算）或「只換這個材質」。新貼圖沿用原圖的翻轉、色彩空間、重複與貼圖變換；長寬比不同、超過輸出的貼圖最大邊長時會提示。
  - 粗糙度／金屬感（glTF 是同一張圖的 G／B 通道）與 AO（R 通道）可以「只換一個通道」：新圖的亮度寫進原圖的那個通道（縮放到原圖尺寸）。
  - 色槽材質的灰階貼圖列有「換原圖（重算灰階）」；色槽材質換顏色貼圖時可勾選「轉灰階」，否則換上彩色圖會提示會變混濁（遊戲是陣營色 × 貼圖）。
  - 「加入貼圖…」：為沒有該種貼圖的材質加入顏色、發光、法線、粗糙度＋金屬感（已打包，或只給粗糙度／金屬感的灰階圖，另一個通道用目前的數值填滿）、AO。沿用網格的貼圖座標，沒有 UV 的網格不能加（請先在 3D 軟體展 UV）。加入顏色貼圖時材質顏色改成白色（顏色與貼圖相乘）。
  - 替換、移除、加入都可以復原。
- **拆分成區塊**：AI 生成的整台機甲或整隻手臂可以直接拆成遊戲的各個區塊（左側「拆分成區塊…」）：
  1. 選零件組合（拆出的區塊存進這些零件的槽位），只勾選要拆的區塊（「全選／全不選」）。每個勾選的區塊會顯示同色的**範圍框**，沒勾選的不顯示。
  2. 用移動、旋轉、尺寸工具把 GLB 的對應部位放進範圍框（例如把 GLB 的左手臂放進左上臂、左前臂、左手的框）。範圍框可以調整：點範圍框（或左側清單）選取區塊後，拖曳框上的白色控制點調整該面、黃色控制點移動整個框，或輸入框的寬／高／深與位移、用「全部放大」（都可以復原）；框上的小菱形是關節點：**拖曳小菱形把關節移到 GLB 實際的關節（轉軸）上**，區塊與範圍框不動、只改轉軸（「重設關節」回到程式模型的位置）；姿勢不同時調整程式模型的姿勢（手臂張開、手肘彎曲、腿張開、膝蓋彎曲，或選區塊輸入它的關節旋轉）。
  3. 「拆分（裁切範圍框）」：每個框裁切出框內的模型，沿框面切開並補上切面；**框外的模型全部移除**。相鄰兩框重疊的地方以連接點的平面切開（例如手肘以上歸上臂、以下歸前臂），只切兩框重疊的範圍（長形的武器穿過別的框時不會被切斷）。拆分後會提示沿骨頭方向比程式模型短（和下一塊之間可能有縫隙）或長（可能插進下一塊）的區塊。之後可以用「框選」改分配或「排除」，或「平面切割」再切一刀；要改範圍框或模型位置按「回到對齊」重拆。
  4. 「全部存到槽位」：只存勾選的區塊，每個區塊以拉直靜止姿勢、原點在關節點的座標存進各自的槽位，拖曳過的關節點同時寫進關節設定（可勾選同時減面到各區塊的預算）。原始 GLB 不會改變，可以換一組勾選（例如右手臂）再拆一次。之後在「組裝調整」也可以再拖曳關節點。
- **最佳化與輸出**（AI 模型面數常常遠超預算）：
  - 「減到預算」把面數減到目標槽位的預算以內（也可以輸入目標面數後按「減面」），以貼圖座標與法線為依據減面，貼圖不會被扯壞；可以復原。拆分的「全部存到槽位」預設會把每個區塊減到各自的預算（建議整台機甲拆分後再減）。
  - 「焊接重複頂點」合併屬性完全相同的頂點（減面時會自動做）。
  - 輸出設定（存到槽位、鏡像、下載、拆分存檔都適用，記在這個瀏覽器）：貼圖最大邊長（預設依預算）、貼圖存成 WebP（有透明的存 PNG）、Draco 網格壓縮（可選）。遊戲與模型庫都能讀 WebP 與 Draco。
- 匯出時節點會攤平成一層、變換歸零。

### 在遊戲中試用（本地模型庫）

- 在遊戲標題畫面「按鍵與操作設定」最下方開啟「使用本地模型庫」；可以分 5 類開關：機甲區塊（含關節設定）、武器、載具、地圖物件、小物件。
- 「**模型組**」選單選擇機甲區塊與武器要用哪一個模型組（所有機甲共用同一組；模型庫刪掉那一組時改用「預設」）。
- 只在**單人模式**（新的傭兵生涯／繼續存檔進去的車庫與單機出擊）套用，敵我機甲只要用到同一個零件都會換；**多人時自動停用**（各端畫面要一致）。
- 進車庫、每次出擊前會自動重新讀取（沒變動的檔案沿用上次的解析結果），也可以按標題畫面的「**重新載入本地模型**」，讀取時有進度條。所以可以一邊開模型庫換檔案，一邊回遊戲看結果。
- 遊戲和模型庫要用**同一種方式開啟**才讀得到同一份瀏覽器暫存：都從同一個伺服器網址（例如 `http://主機/` 與 `http://主機/models`），或都直接開 HTML 檔（同一個瀏覽器）。讀不到時維持程式模型。
- 設定畫面會列出讀取結果：**失敗**（壞檔、蒙皮網格、不接受 GLB 的槽位）改用程式模型；**提醒**（超過預算、尺寸或原點偏差）照樣套用；「套用中的 GLB」列出每個檔案在遊戲中已使用的次數。車庫也會顯示這台機甲有幾個區塊用了 GLB。
- 換模型只改外觀：碰撞、命中判定、機甲身高等數值一律維持程式模型的值。

## 2. 單位、座標與朝向

| 項目     | 規格                                                                                         |
| -------- | -------------------------------------------------------------------------------------------- |
| 單位     | 1 單位 = 1 公尺（模型庫所有尺寸都以公尺標示）                                                |
| 上方     | +Y                                                                                           |
| 正面     | **+Z**（glTF／Blender 預設匯出方向即可；遊戲載入時會自動轉成遊戲內的 −Z）                    |
| 左右     | 機甲面向 +Z 時，**機甲的右手在 −X**、左手在 +X（Blender 前視圖中，右手在畫面左邊）           |
| 參考尺寸 | 二足機甲頭頂約 3.3 m（含天線約 3.8 m），人形剪影 1.8 m；各部位比例見第 3 節                  |
| 格式     | glTF 2.0 二進位（.glb），貼圖內嵌；可用 Draco 網格壓縮與 WebP 貼圖（例如 glb-shrink 的輸出） |

模型庫的每一格與檢視窗都會畫出**原點與三軸**（白點＝原點，箭頭用 glTF 軸名：X 紅、Y 綠＝上、Z 藍＝正面），檢視窗另外標出所有**連接點**（黃色菱形＋短三軸，三軸表示連接點的旋轉），可在「顯示」中開關。

## 3. 機甲區塊與原點

每個區塊的**原點（0, 0, 0）是它的旋轉中心**，也就是它接到上一塊的位置。**原點不必在 3D 軟體或 GLB 編輯器裡對齊**：在「組裝調整」頁拖曳關節點（只動關節）時，區塊不動、系統自動把新的旋轉中心寫回子區塊的 GLB（在場景根部加一個 `rubicon_origin` 節點，只改 GLB 的 JSON，不重新編碼頂點與貼圖）；拆分時拖曳的關節點也一樣。下表是程式模型的原點位置，照它製作可以少調整。左右兩側是**各自獨立的檔案，不會鏡像**（貼圖上的文字不會反過來）。

| 零件           | 區塊（槽位 id）                                                                       | 原點                                                                     |
| -------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 頭部           | `head/<id>`                                                                           | 脖子轉軸（頭部底面中心）                                                 |
| 核心           | `core/<id>`                                                                           | 腰部（核心底部坐在襠部上的點）                                           |
| 推進器（背包） | `booster/<id>`                                                                        | 背包座（背包中心）；**噴焰是特效，不要做進模型**                         |
| 手臂           | `arms/<id>/r_upper`、`r_fore`、`r_hand`，左側為 `l_…`                                 | 上臂（含肩甲）：肩關節轉軸；前臂：手肘轉軸；手：手腕轉軸                 |
| 二足、逆關節腳 | `legs/<id>/pelvis`＋`r_thigh`、`r_shin`、`r_foot`，左側為 `l_…`                       | 襠部：地面中心（兩腳之間的地面）；大腿：髖關節；小腿：膝關節；腳掌：腳踝 |
| 四足腳         | `legs/<id>/body`＋`fl_thigh`、`fl_shin`（`fl` 左前、`fr` 右前、`bl` 左後、`br` 右後） | 主體：地面中心；大腿：髖關節；小腿（含腳）：膝關節                       |
| 履帶           | `legs/<id>/body`                                                                      | 地面中心（整塊，不會動）                                                 |
| 手持武器       | `weapon/<id>/r`、`weapon/<id>/l`                                                      | 握把（手的握點）；槍口朝正面                                             |
| 肩上武器       | `back/<id>/r`、`back/<id>/l`                                                          | 肩上武器座                                                               |

- **關節外觀屬於下一塊**：手肘圓柱做在前臂、膝蓋做在小腿、髖球做在大腿、腳踝圓柱做在腳掌。
- 四肢以**自然下垂**的姿勢製作（沿 −Y 方向）；彎曲角度由遊戲動作決定。範本裡手臂的彎曲是程式的展示姿勢，製作時請拉直。
- 武器以**遊戲內實際尺寸**製作（模型庫顯示的就是遊戲尺寸）；左手武器沒有自己的 GLB 時，會暫用右手的檔案（不鏡像）。
- 完整機甲（`mech/`）只用來預覽區塊組合的結果，**不接受整台的 GLB**。
- **比例**（寫實比例，約 10.7 頭身）：二足站立時腳踝離地 0.30 m、膝 1.12 m、髖 1.94 m（左右各 ±0.34 m）、腰 2.22 m、胸頂 3.15 m、頭 3.02～3.33 m；胸寬約 0.88 m、細腰約 0.48 m、肩甲外緣總寬約 1.9 m；上臂（肩→肘）0.48 m、前臂（肘→腕）0.52 m（前臂比上臂粗）、手約 0.3 m。逆關節腳的髖關節較低（約 1.87 m）；四足、履帶的上半身用同一組比例，以腰部支柱架高。實際數值以模型庫顯示的程式模型為準（`src/render/mech-model.js` 的 `CUBE`）。

模型庫會比對 GLB 與程式模型的外框：尺寸差超過 15% 警告、超過 50% 錯誤。機甲區塊的原點和程式模型不同時只列為說明（旋轉中心在組裝調整頁設定）；其他模型（載具、地圖物件等）外框中心或底部高度明顯不同時，代表原點可能放錯。

**自動貼地**：腿部（襠部／主體、大腿、小腿、腳掌、履帶）換成 GLB 或改過腿部的連接點時，遊戲與模型庫在建立機甲時以站姿量測腿的最低點，整台機甲上下移動到和程式模型的腿同樣的高度，腳底不會懸空或陷進地面；腿全是程式模型且沒改連接點時不移動。腳底有不想碰地的裝飾時，在組裝調整頁選腿部的根區塊（襠部／主體）輸入「離地微調」（存成關節設定裡根區塊的 `ground`，`p[1]` 為公尺）。只影響外觀，碰撞與判定仍用程式模型的數值。

## 4. 連接點

區塊之間的接點由**父區塊**決定，換零件時子區塊會自動接到新父區塊的連接點上：

| 父區塊     | 連接點                               |
| ---------- | ------------------------------------ |
| 核心       | 脖子、左右肩、背包座、左右肩上武器座 |
| 襠部／主體 | 腰（核心座）、左右髖（四足為四個髖） |
| 上臂       | 手肘                                 |
| 前臂       | 手腕                                 |
| 手         | 武器握點                             |
| 大腿       | 膝                                   |
| 小腿       | 腳踝                                 |
| 背包       | 左右噴口（噴焰特效從這裡噴出）       |

連接點的預設位置以程式模型為準（範本 GLB 裡各區塊的位置）。換成 GLB 後如果接不準（例如新做的上臂比較長，手肘要往下移），在模型庫調整：

1. 打開**父區塊**的檢視窗（例如要移動手肘就開上臂），右側「關節設定（連接點）」列出這個區塊的所有連接點。
2. 按「選取」（或直接點畫面上的黃色菱形），拖曳三軸箭頭移動；也可以直接輸入**位置（公尺）**與**旋轉（角度）**。數值是 glTF 座標（Y 朝上、+Z 為正面），和 Blender 匯出的座標一致。
3. 切到「組合預覽」並播放動作，確認子區塊接得剛好、轉動時不穿幫。組合預覽中也可以直接調整，子區塊會即時跟著移動。
4. 修改先存在瀏覽器（標示「已修改」，按「重設」可還原）。確定後按「**匯出關節設定**」得到 `joints.json`，放到 `src/assets/models/joints.json` 重新建置，**遊戲與模型庫就會套用**。

也可以在模型庫上方的「**組裝調整**」頁籤，在整台機甲上逐一調整：

- 左側自由選擇每個部位的零件（或從現有機甲載入），每一塊可以切換用 GLB 或程式模型；預組可以命名儲存、匯出／匯入。
- 點畫面上的區塊、黃色菱形或右側清單選取；拖曳箭頭移動（W）、旋轉環旋轉（E），或輸入數值。
- 工具列的「**只動關節**」（預設）：移動關節點時接在上面的區塊不動、只改轉軸，子區塊的原點自動寫回它的 GLB（子區塊是程式模型或暫用另一側的檔案時無法改原點，會跟著移動）；「**零件跟著動**」：子區塊與下游的區塊一起移動。選取區塊（不是菱形）時拖曳箭頭是移動整個零件（改它接上的連接點，下游一起移動）。
- 右側的組裝層級**以核心為根**：核心 →◆腰（核心座）→ 襠部／主體 →◆左右髖 → 腿。選取襠部（或四足／履帶的主體）拖曳箭頭或用方向鍵，是整組腿相對核心移動：拖曳中核心在畫面上不動，放開後改的是腰的連接點，並自動貼地。（遊戲內部仍以腿為根、腰的連接點存在襠部上，動作與存檔格式不變。）
- 「拉直靜止姿勢」（關節角度歸零，和 GLB 的製作姿勢一致）是預設；也可以播放動作，暫停後拖曳時間軸停在任一幀調整。
- 「對稱編輯」讓左右一起改；「複製到另一側」把這一側的值鏡像過去；Ctrl+Z／Ctrl+Y 復原／重做；方向鍵微調（←→ X、↑↓ Y、PageUp／PageDown Z，Shift 大步進），步進與拖曳吸附可以自己設定。
- 「顯示」可以開關：高亮選中區塊、其他區塊半透明、隱藏無關區塊、穿幫提示。穿幫提示會列出相鄰區塊之間超過 2 cm 的縫隙，或子區塊有一半以上嵌進父區塊的情況（移動中用外框估算，停下來用網格精算，都只是提醒）。
- 這裡改的一樣是**零件的連接點**：會套用到所有使用同一個零件的機甲，和區塊檢視窗共用同一份設定。

`joints.json` 的格式（只需要寫有修改的連接點）：

```json
{
  "arms/a_std/r_upper": { "elbow": { "p": [-0.28, -1.2, 0], "r": [0, 0, 0] } }
}
```

旋轉通常保持 0；武器握點預設繞 X 轉 90°（武器沿前臂方向）。背包噴口的旋轉決定噴焰方向（旋轉為 0 時往下噴）。

## 5. 其他模型

製作尺寸一律 ×1（模型庫的「原始尺寸」）；遊戲依倍率放大（例如 Boss）或依隨機尺寸縮放。

**載具**：會動的部位拆成區塊，原點是它的旋轉中心；完整載具（`vehicle/tank`、`vehicle/heli`、`vehicle/boss_helios`、`vehicle/transport_train`）只預覽區塊組合，不接受整台的 GLB。

| 載具                    | 區塊（槽位 id）                                                | 原點                                             |
| ----------------------- | -------------------------------------------------------------- | ------------------------------------------------ |
| 戰車                    | `vehicle/tank/hull` 車身、`vehicle/tank/turret` 砲塔（含砲管） | 車身：地面中心；砲塔：砲塔旋轉中心（離地 1.8 m） |
| 直升機（Boss 同樣三塊） | `vehicle/heli/body`、`rotor` 主旋翼、`tail` 尾旋翼             | 機身：傾斜中心（離地 1.2 m）；旋翼：各自的軸心   |
| 無人機                  | `vehicle/swarm`                                                | 機身中心（離地 0.6 m）；尾焰是程式特效           |
| 運輸列車                | `vehicle/transport_train/loco` 機車頭、`…/car` 車廂            | 這一節的地面中心；車廂依節數重複                 |
| 運輸貨車、空襲轟炸機    | `vehicle/transport_truck`、`vehicle/bomber`                    | 地面中心；轟炸機為機身中心，機頭朝正面           |

**地圖物件**（`prop/`）：原點在地面中心（岩石在中心、橋面板在頂面）。尺寸隨機的物件以模型庫的代表尺寸製作，遊戲依每個物件的長寬高**分別縮放**（貼圖會跟著拉伸），外觀和碰撞一致：貨櫃（長邊沿 X）、方格高柱、岩石、柱子／路燈桿、散落碎塊、橋面板（護欄沿 X）、支柱。停放卡車、隧道口為固定尺寸。命名為 `main` 的材質會改成遊戲給這個物件的顏色（貨櫃與卡車的隨機色、主題的岩石色等）；地圖物件不加墨線描邊。疊放貨櫃、掩體由其他物件組成（用貨櫃、橋面板、支柱的 GLB）；高台、公路、鐵路不接受 GLB。

**小物件**（`small/`）：原點在物件中心。掉落物 GLB 只取代會浮動旋轉的方塊，底下的光環是程式特效；彈體的 `glow` 材質會改成武器的彈色，子彈依彈速沿前後拉長（以 0.9 倍長度製作），飛彈尾焰是程式特效。

## 6. 材質與配色

- 一律使用 **PBR 材質**（Principled BSDF → glTF metallic-roughness）。受擊閃光會改變材質的自發光，無光照（unlit）材質只適合貼花或發光面。
- **依材質名稱換色**：名稱為下列其中之一的材質（不分大小寫，可帶 `.001` 這類後綴），遊戲會依陣營配色（玩家、敵人、具名 AC、多人四色）改成對應顏色，貼圖只負責髒污、面板線等明暗細節：

  | 名稱                     | 用途                               |
  | ------------------------ | ---------------------------------- |
  | `main`、`main2`、`main3` | 主色（大面積裝甲）                 |
  | `sub`                    | 副色                               |
  | `acc`                    | 點綴色（黃色條紋等）               |
  | `joint`                  | 關節、機械部分                     |
  | `grey`                   | 灰色裝甲                           |
  | `gun`                    | 武器金屬                           |
  | `visor`、`glow`          | 面罩、發光部位（會一併設定自發光） |

- 其他名稱的材質保留原本的顏色與貼圖（不隨陣營改變）。兩種方式可以混用。
- 墨線描邊由遊戲自動產生，模型不需要自己做描邊。
- 不使用蒙皮骨架（skinned mesh 會被判為錯誤）；會動的部位一律拆成區塊。

## 8. 其他注意事項

- GLB 內的動畫不會被使用（動作由程式驅動），模型庫只會提示。
- 不要在根節點加整體縮放或位移來「修正」尺寸，請直接在建模軟體裡以正確單位製作。
- 地圖物件在遊戲中的尺寸有隨機範圍（模型庫備註欄有寫）；以代表尺寸製作，遊戲依隨機尺寸縮放（見第 5 節）。
- 規格檢查的數值定義在 `src/render/glb.js`（`GLB_BUDGET`、`PALETTE_SLOTS`），區塊與連接點定義在 `src/render/mech-model.js`（`partPieces`、`pieceConns`），載具區塊在 `src/render/vehicle-models.js`，地圖物件的代表尺寸在 `src/world/prop-models.js`，調整時請同步更新本文件。
