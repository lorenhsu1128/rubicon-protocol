# 各章開場／章末與抉擇演出的分鏡（第二版：每章一種導演風格）

> 狀態：實作中。取代第一版（每章同一套「黑底字卡 → 空景 → 通訊 → 宿敵名牌 → 追尾對射 → 章名卡」的模板）。
> 劇本在 `data/cine/ch<章>.js`，各章專用的效果在 `game/cine-c<章>.js`（Game 的 mixin：`cineHook_*`、`cineOv_*`、`cineRender_*`，見 `docs/cinematics.md`）。台詞沿用 `CHAPTER_TEXT`／`story-comms.js`（依抉擇的 `pickLines`），〔 〕是畫面。

## 為什麼要改

第一版每一章都用 `kit.js` 的同一組組件依序拼成：結構相同、一句台詞一個鏡頭（3.4～7 秒等速）、鏡頭動作只有 crane／pan／push／fly／low 輪流用、配樂只有開場 `cine_drive`＋章末 `cine_tension`、調色只差時間。結果換了地圖還是同一支預告片。

參考：

- 《機戰傭兵6》：劇情大多靠簡報與無線電，動畫很少，但每一段只做「一個記得住的畫面」（冰蟲破冰、巴爾特烏斯的導彈幕、熔爐清掃機的爐口），每個 Boss 的登場方式都不一樣。
- 《皇牌空戰 04》：用孩子敘述的插畫繪本講故事——敘事手法和戰鬥畫面完全不同。
- 《潛龍諜影》：無線電本身就是一種畫面（Codec）。
- 《泰坦降臨 2》：每一章有自己的機制與視覺主題。
- 電影的類型語言：西部片（極遠景＋眼睛特寫的對決）、恐怖片（有限的視野、畫面邊緣的動靜、靜默）、太空片（寂靜、長鏡頭）。

## 原則

1. **每章一種類型片的鏡頭語言＋一個專屬手法＋一首專屬配樂＋自己的調色**。共用的只留字幕樣式與遮幅。
2. **不要再依序套 `vista → comm → rival → shootout → chapterCard`**。`kit.js` 的組件可以用，但結構、節奏、章名出現的方式每章不同；只有第 6 章的 ZENITH 刻意呼應第 1 章的對決。
3. **節奏依章不同**，不是一句一鏡：有的長停留、有的對拍快剪、有的一鏡到底。
4. 抉擇演出（選前／選後）也用該章的手法。
5. 長度：開場 45～70 秒、章末 30～50 秒、抉擇選前 8～12 秒、選後 10～18 秒。

## 第 1 章　荒野的訊號——西部對決

- 調色：暖橘、高對比、顆粒、輕微暗角。節奏：慢，長停留 8～12 秒。
- **開場**
  1. 〔極遠景的地平線，熱浪扭曲，一台小小的機體剪影〕只有風聲，8 秒沒有台詞。
  2. 舊天線的紅光（特寫，紅光一明一滅）＋台詞。
  3. BASTILLE 從**砲台的視角**：從砲口往外看，預警紅圈落在卡斯特隆車隊上，連鎖爆炸。
  4. 霍斯特的委託：只有聲音，畫面是主角機體的腳步踩過沙地（低角度）。
  5. **對決**（取代追尾對射）：RUST 與主角隔著 40 m 站定；在眼燈特寫、武器（手指）特寫、遠景之間來回切，每切一次間隔變短；飛沙橫過畫面；一聲槍響 → 全黑 → RUST 跪倒。
  6. 章名用西部片的大字直接壓在遠景上（不是黑底字卡）。
- **章末**：營火旁的一鏡到底（約 30 秒不剪接），鏡頭慢慢拉遠到星空；四家委託方的台詞只用聲音疊進來（字幕＋說話者）；最後 3 秒軌道站的光點閃一下。

## 第 2 章　工業帶的契約——分割畫面

- 調色：一半卡斯特隆的橘、一半艾瑟立克的藍。鏡頭：固定機位、對稱構圖、沿軌道等速平移，沒有手持晃動；剪接對準機械聲（閘門、起重機）的節拍。
- **開場**
  1. **畫面切成左右兩半**（`cineRender_c2split`）：左＝卡斯特隆（起重機吊貨櫃、閘門關上），右＝艾瑟立克（運輸車裝天線核心、冷卻槽灌水），同一時間各做各的；兩邊的台詞互相蓋過。
  2. HALBERD 從**彈道視角**登場：鏡頭跟著電磁砲彈飛過整個河谷打中山壁 → 閃白。
  3. SLUICE 在壩頂（固定的監視器角度）。
  4. 高潮：主角從畫面中線跳過去，分割線碎掉，回到整個畫面的戰鬥。
  5. 章名分成兩半從左右合上。
- **抉擇 1 選前**：分割畫面，左右兩家的光柱，中線就是倒數條，兩邊的委託方輪流說話。
- **抉擇 1 選後**：卡斯特隆＝閘門關上、下游河道乾涸，左半邊（工廠燈亮）擴張吃掉右半邊；艾瑟立克＝蒸氣衝天，右半邊吃掉左半邊，懸賞令跳出。
- **章末（依抉擇，手法不同）**：卡斯特隆＝下游城鎮的監視器畫面一格一格斷線（CCTV）；艾瑟立克＝R-07 的懸賞檔案逐行列印、紅色印章蓋下。共通結尾：冰原上難民營的訊號燈熄滅。

## 第 3 章　冰原之下——恐怖片

- 調色：幾乎黑白、藍灰、霧很近（可見距離約 20 m）。配樂幾乎沒有，只有低頻、呼吸、無線電雜訊；只有嚇人的那一刻有一記打擊。節奏不規則：靜很久然後突然。
- **開場**
  1. 難民營監視器的錄影（`cineOv_c3cctv`：時間碼、雜訊、跳格）：帳篷被雪埋了一半，畫面右下的人影一跳格就不見了。
  2. 諾拉的通訊：雜訊很重、斷斷續續。
  3. 主角在暴風雪中走，手持晃動、畫面邊緣有東西一閃而過。
  4. 冰面下巨大的黑影游過（鑽地蟲不直接露臉）＋冰裂聲。
  5. **熱感應視角**（`c3thermal`：灰階＋熱色盤）：一般畫面看不到，切成熱感應才看到 WHITEOUT 就站在主角身後 → 打擊 → 對射幾秒。
  6. 章名被雪慢慢蓋住（不是淡入）。
- **章末**：檔案的形式——研究所終端機（打字聲、檔名被塗黑、「週期」數字瘋狂跳動），研究所的燈一盞盞往鏡頭方向熄滅，黑暗中 SPECIMEN 的紅色眼燈亮起（依抉擇的台詞）。

## 第 4 章　構造體——垂直一鏡到底＋倒數

- 調色：冷金屬、雲上的強光。配樂一路堆高。
- **開場**
  1. 畫面角落一直有 COUNTDOWN 的倒數（`cineOv_c4count`），整段開場就是一次倒數，最後一秒＝發射架點火。
  2. 從 Grid 086 最底層開始**一鏡到底往上升**（約 40～60 秒不剪接）：穿過一層層平台、爬行機、底部砲塔、SPIRE，一路升到雲上。
  3. **滑動變焦**（dolly zoom：鏡頭往後退、同時縮小 fov）讓構造體突然變深。
  4. 派克與諾拉的對話：同一個鏡頭裡兩種顏色的字幕。
  5. 章名直向從下往上捲。
- **抉擇 2 選前**：發射控制室的倒數 T−10，兩個按鈕的光（綠＝維爾威、黃＝聖域）。
- **抉擇 2 選後**：維爾威＝從下往上一鏡跟著火箭升空，尾焰掃過外圍聚落；聖域＝大門關上，倒數停在 00:03 凍結。
- **章末**：霍斯特的手寫信（字跡逐字寫出），背景很淡地透出軌道站的光點，比上一章大。

## 第 5 章　洋上的抉擇——電視牆與新聞轉播

- 調色：螢幕的藍白、探照燈；高潮是直升機轉播（長焦、晃動、LIVE）。節奏快、多畫面。
- **開場**
  1. **電視牆**（`cineRender_c5wall`／`cineOv_c5wall`）：4～9 格，每格一家的宣傳頻道（台標、跑馬燈）；艦隊抵達、探照燈、UNDERTOW 浮出先在小螢幕裡出現，再「切到現場」變成全畫面。
  2. AEGIS 的護盾從電視牆的一格開始長大，蓋滿整個畫面。
  3. 高潮的突擊用直升機轉播的鏡頭：長焦、晃動、畫面角落「LIVE」。
  4. 章名是新聞頭條的跑馬燈。
- **章末**：全世界的螢幕同時變白，軌道站廣播「KEY-07。請前往中樞。」→ 倒數 72:00:00 開始跳 → 舞台劇式的固定鏡頭：四張椅子的會議桌，對稱構圖，第四張空著 → 所有人轉頭看鏡頭 → ECHO 第一次沒有無線電雜訊的聲音。

## 第 6 章　軌道——寂靜

- 調色：純黑、強光、高反差。極長鏡頭。
- **開場**
  1. 全程從**駕駛艙看出去**（`cineOv_c6cockpit`：高度、速度、熱罩溫度）：發射、震動、熱罩發紅、雲海往下掉（依抉擇 2：維爾威的發射台或聖域解封一次）。
  2. 衝出大氣層的那一刻**聲音全部消失**：配樂停，只剩駕駛艙的機械聲與 ECHO 的雜訊。
  3. 軌道站用極長的鏡頭慢慢轉進畫面，鏡頭翻滾，沒有固定的上方。
  4. 四個委託方的回答：無聲的快切，只有字幕。
  5. ZENITH 的對決**刻意呼應第 1 章**：同樣的剪法（眼燈、武器、遠景），在無重力的外環，最後槍口對槍口停住，不開槍。ZENITH「這一次，你能走到哪裡？」
  6. 沒有章名卡，只有軌道站的倒數。
- **最後的抉擇 選前**：寂靜、駕駛艙視角，中樞的門（第 3 周目三扇）的光，委託方的頻道一個個亮起；ECHO 沉默。
- **選後**：交出＝「認證完成。KEY-07。盧比孔協定，執行。」→ 錄影帶倒轉的效果（雲、海、荒野）；墜落＝駕駛艙看著軌道站拖著火光落進雲海、故障保險的紅字；彼岸＝畫面右上的頻道徽章一個個熄滅，ECHO「我們走吧。」推進器一排排亮起，星球在背後變小。
- 第 6 章沒有章末（接結局畫面與回收程序）。
