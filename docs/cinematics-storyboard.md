# 各章開場／章末與關鍵抉擇的過場分鏡（提案）

> 狀態：已實作（`data/cine/ch1.js`～`ch6.js`、組件 `kit.js`；抉擇演出接在 `game/campaign.js` 的抉擇出口）。下面是分鏡的原始提案，實作時有些鏡頭依地圖與模型調整過。
> 原則：**熱血**＝每段都有一個「主角出手」的高潮鏡頭（追尾視角對射、鎖定框、慢動作、閃白）；**因果**＝開場交代為什麼去、章末留下下一章的鉤子；**抉擇**＝選擇前有壓迫感的倒數，選擇後立刻讓玩家看到代價。
> 長度：開場 45～60 秒、章末 30～45 秒、抉擇演出 15～25 秒（選前 8～10 秒＋依選項 10～15 秒）。台詞沿用 `CHAPTER_TEXT`／`story-comms.js`，括號〔 〕是畫面。

## 共通的鏡頭語言

| 名稱 | 做法 | 用在 |
|---|---|---|
| 追尾對射 | 機體右肩後方的追尾視角、鎖定框套住目標、HUD（彈數／EN／目標 AP 與 ACS）、快速推進閃避 | 每段的高潮 |
| 失衡處決 | 打出 ACS 過載 → 0.25 倍慢動作 → 閃色 → 近距離連射／近戰，ECHO「對方失衡！」 | 宿敵、Boss |
| 登場名牌 | 低角度仰拍＋左下名牌（名稱／一句話），背景爆炸 | 宿敵、Boss |
| 通訊分割 | 畫面一側暗下，說話者的徽章＋聲紋波形，另一側是戰場 | 委託方的台詞 |
| 抉擇倒數 | 畫面凍結成冷色、兩個（三個）出口的光柱、委託方的徽章輪流閃、心跳音、計時條 | 抉擇演出 |
| 代價蒙太奇 | 選擇後 3～4 個快切：下游、難民、懸賞、燃燒的聚落，每切一記重低音 | 抉擇演出、章末 |

## 第 1 章　荒野的訊號（南部荒野）

**開場（約 50 秒）**
1. 〔黑畫面〕舊天線的訊號聲 → 〔低空飛越沙丘，夕陽〕「南部荒野。舊時代的礦場和砲台，在沙裡埋了幾十年。」
2. 〔沙中露出半截的舊天線，紅光一明一滅，鏡頭繞一圈〕「三天前，荒野深處的一座舊天線突然自己啟動。」
3. 〔礦坑口，BASTILLE 的砲台一門門抬起，預警紅圈落在卡斯特隆車隊上，連鎖爆炸〕「同一天，砲兵陣地 BASTILLE 跟著醒了過來。」
4. 〔通訊分割：霍斯特〕「合約就是合約。礦場拿回來，報酬照付。」
5. 〔RUST 從廢鐵堆裡跳出，名牌「RUST／廢鐵也是錢」，對著鏡頭開火〕
6. **高潮**：〔追尾對射：主角衝下沙丘，鎖定 RUST，快速推進閃過火箭，導彈齊射〕
7. 〔章名卡：第一章　荒野的訊號〕

**章末（約 40 秒）**
1. 〔天線核心在主角手上發著紅光〕「你把天線核心交了出去。報酬入帳。」
2. 通訊分割四連切：卡斯特隆（工廠煙囪）、艾瑟立克（研究所燈光）、維爾威（數錢的手指＝貨幣圖示跳動）、聖域（下游城鎮囤水）

4. 〔主角的機體在營火旁跪坐，鏡頭慢慢拉遠到星空〕ECHO「……我也不知道。睡吧，明天還有工作。」

## 定案

1. 抉擇演出：做。抉擇出口出現時在目前的戰場上播選前的倒數（live，遊戲暫停），走進出口後播選後的代價蒙太奇，再到轉場畫面；單人、劇情動畫開啟時才播，可略過。
2. 每章開場的高潮：和宿敵追尾視角對射；Boss 只登場。
3. 6 章一次做完，每章一個 commit。
