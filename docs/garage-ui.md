# 機甲庫的換裝介面

機甲庫（`state` 'garage'）的操作介面改版：原本是三欄文字（左邊 13 個部位按鈕加一長串零件說明、右邊 30 行數值加 7 個按鈕），改成遊戲式的裝備畫面。格納庫的場景與演出（鏡頭、全像預覽、實體換裝、維修、出擊）照 `docs/garage-hangar.md`，這份只管介面。

提案頁（四個方向的示意圖）：方案 D「雙翼裝備欄」（Destiny 2、魔物獵人 世界）當主體，加上方案 B「機體標註」（Cyberpunk 2077 義體醫生、鋼彈創壞者 4）的部位鏡頭、標註線與全像預覽。

## 定案（使用者的選擇，2026-10-26）

1. **版面**：D 的雙翼裝備欄——武器在機體左邊、機架與內裝在右邊，都是方形圖示格；選一格，旁邊彈出零件的縮圖格子與小卡片。
2. **B 的部位鏡頭與標註**：選一格時鏡頭轉到那個部位（`hangarFocus`，已有）；格子用**標註線**連到機體上的部位，標註線只用**固定角度的斜線＋水平線**（不是任意角度的直線）；游標停在零件上時全像預覽（`hangarPreviewBuild`，已有）。
3. **零件縮圖：做**。用遊戲本身的模型離屏渲染。
4. **數值：全部都要看得到，多用圖表與六角圖**。裝備頁一直顯示六角性能圖與四條量表，規格頁把原本 30 行數值全部改成圖表。
5. **設定類（機體配色、出擊地圖、模型組、模型組的機甲）放在機甲庫的子分頁**。

```text
│ ▢ 左手 HG-020   └──╲   （機體）              ╱─────┘    BD-011 核心 ▢ │
│ ▢ 右背 MS-4  ┌ 零件格子 ┐                         …                       │
│ ▢ 左背 —     │ ▣▣▣▣▣ │                                    火控 ▢ │
│ ▢ 消耗品 1   │ 小卡片    │           ┌六角┐                                 │
│ ▢ 消耗品 2   └──────┘           └───┘                                 │
│      [ AP ▬▬▬ ] [ 火力 ▬▬▬ ] [ 負重 ▬▬▬ ] [ EN 負載 ▬▬▬ ]              │
│ [靶場][紀錄][駕駛員][作戰室][隨機組裝][回標題]                      [出擊] │
└──────────────────────────────────────────────────────────────┘
```

- **上方列**（`#gTop`）：標題、場合（`#gCtx`）、COAM（`#gCoam`）、任務一行（`#mcTitle`＋`#mcDesc`，滑鼠停留看全文）、子分頁（`#gTabs`：裝備／規格／設定）。
- **雙翼**（`#slots` 裡的 `#gWingL`／`#gWingR`，`.slot` 是 `button`）：左＝右手、左手、右背、左背、消耗品 1、2；右＝頭部、核心、手臂、腳部、推進器、發電機、火控。每格：方形縮圖（裝備中的零件）＋部位名＋型號。
- **零件格子**（`#gFly`，選中的格子旁邊）：這個部位的全部零件（`#partList .part`，`data-pid`），縮圖格子；裝備中的有黃點、沒擁有的變暗並標價格；游標停留（手把的焦點）時下方的小卡片（`#gTip`）顯示零件名、屬性、關鍵數值與換上後的差值（條狀＋綠／紅），以及「裝備／購買」按鈕。消耗品格子另外有購買數量。
- **標註線**（`#gCallout` 畫布）：每個有外觀位置的部位格（消耗品除外）一條，選中與游標停留的亮（警示黃），其他淡；從格子內側的邊出發走**水平線**，接一段**固定 45° 的斜線**到機體上的點（點＝`hangarView` 用的節點：頭、軀幹、手、肩上武器座、背包、腳；發電機指軀幹、火控指頭）。水平距離不夠走完斜線時，斜線縮短、剩下用水平線補（兩段仍是固定角度）。
- **六角性能圖**（`#gHex`，裝備頁的右下）：火力、裝甲、機動、EN、穩定、射程六軸，實線＝目前、虛線＝游標停留的零件換上後。
- **量表**（`#gMeters`）：AP、火力（持續 DPS）、負重（總重量／負重上限）、EN 負載（負載／輸出）；換零件的差值是條上的一段（綠＝變好、紅＝變差），超過上限變紅。
- **底部列**（`#gActions`）：次要按鈕（靶場、靶場紀錄、駕駛員、前往作戰室、隨機組裝、回標題）縮成一排小按鈕，右下一個大的主要按鈕（出擊／繼續作戰／返回作戰室／返回大廳，依場合）；不能出擊的原因（`#gWarn`）在主要按鈕上方。主線轉場整備的修理／補彈／修復套件（`#gCamp`）在底部列上方。
- **規格頁**（`#gSpec`）：大的六角圖＋各軸的數值；武器的理論火力（每把武器的瞬間／持續 DPS 橫條，屬性顏色）與預估命中率（90 m／180 m 的長條）；三種減傷的長條；機動（速度、QB 速度與消耗、跳躍高度、空中跳次數、懸浮耗能）；EN（容量、回復、負載／輸出）；火控（鎖定距離、近／中／遠輔助的折線、導彈鎖定時間、射擊適性）；駕駛員加成以「(+n)」標出（`#stats` 保留給這頁的文字數值）。
- **設定頁**（`#gSet`）：機體配色（色票，`#gPal`）、出擊地圖與變體（`#gMap`）、模型組的機甲（`#gMechs`）、模型組（`#gModelSet`）、本地模型（`#gLocal`）。

## 六角性能圖的六軸

每軸 0～1，依全部零件的範圍正規化（`data/garage-hex.js` 的 `hexScores(asm, pm)`，純函式；範圍在第一次呼叫時由 `PARTS` 算一次）：

| 軸 | 數值 | 範圍 |
|---|---|---|
| 火力 | 合計持續 DPS（`garageFire` 的 sus） | 0 ～ 每個武器槽最高的持續 DPS 加總 |
| 裝甲 | 有效 AP（AP 與平均減傷） | 四個機架零件 AP 最小加總 ～ 最大加總，乘上減傷 |
| 機動 | 地面速度與 QB 速度的平均 | 各自依腳部／推進器的範圍 |
| EN | EN 容量與回復的平均，再扣掉負載比例的一半 | 發電機的範圍 |
| 穩定 | 姿態穩定 | 四個機架零件的最小～最大加總 |
| 射程 | 鎖定距離與武器平均射程 | 火控與武器的範圍 |

## 分期

### 第一期：版面、標註線、圖表（已完成）

- `index.html` 的 `#garage` 改成上方列＋雙翼＋零件格子＋底部列＋規格頁＋設定頁；`garage.js` 的 `renderGarage` 拆成 `garageSlotsUi`、`garageFlyUi`、`garageTipUi`、`garageMetersUi`、`garageSpecUi`、`garageTabUi`。
- 部位與零件先用圖示（`render/garage-icons.js` 的 SVG，依部位與武器種類）。
- 標註線、六角圖、量表、規格頁的圖表都畫在 DOM／SVG（不是 WebGL）。
- 格納庫的鏡頭：機體放在兩翼（＋打開的零件格子）中間，規格頁、設定頁時放在左邊空出來的地方（`hangarCamera` 的 view offset 改讀新的元素）。
- 標註線：斜線的角度只用 45°、60°、75°（先試 45°，水平距離不夠才換陡的），選中與游標停留的部位格是警示黃，其他淡白；出擊演出與實體換裝播放時不畫。
- 進機甲庫時一律在裝備頁、零件格子打開；再點一次選中的部位格收起零件格子。返回作戰室／關卡選單是那時的主要按鈕，移到右下（`campGarageUi`）。
- 零件格子的每一格另有讀螢幕用的完整說明（`.srOnly`：零件名＋屬性、傷害、射程、理想射程、輔助…），冒煙測試也讀它。
- 手機橫式（`max-height: 540px`）先做了基本版：兩翼只剩縮圖、零件格子打開時量表收起、六角圖只在規格頁、規格頁與設定頁佔滿寬度。
- 冒煙測試：地圖、模型組的選單在設定頁，測試先 `gSetTab(page)` 切過去。

### 第二期：零件縮圖（已完成）

- `render/part-thumbs.js`：離屏的小場景＋正交鏡頭，`buildMech` 換上那個零件、只顯示那個零件的區塊（`rig.pieces` 的槽位 id 第二段＝零件 id），渲染到 128×128 的 render target，讀回成 data URL；依「部位＋零件 id＋模型來源＋配色」快取（256×256 拍、縮成 128；render target 的貼圖設成 sRGB，直接當圖片用），一格只拍一張（零件格子打開時才排隊，每格最多拍一張，不卡畫面）。發電機、火控、消耗品沒有外觀，用圖示。

### 第三期：平板、手機、手把（已完成）

- 平板橫式（1180×820）：同一個版面（兩翼、零件格子、六角圖、量表都放得下）。
- 手機橫式（844×390，`max-height: 540px`）：兩翼只剩縮圖（38 px）、零件格子在部位格旁邊（可以捲動）、零件格子打開時量表收起、六角圖只在規格頁、規格頁與設定頁佔滿寬度、單欄。
- 手把：LB／RB 換部位格（`#slots` 的 `data-padtabs`），十字鍵在零件格子裡移動（焦點＝全像預覽與小卡片），A 裝備，**Y 切換裝備頁 ⇄ 規格頁**（`pad-ui.js`）。
- 冒煙測試 `testGarageUi`：雙翼 6＋7 格、零件格子在右翼旁邊、小卡片、游標停留的預覽（六角圖虛線、量表差值）、標註線（畫布上有警示黃的線）、零件縮圖、購買並裝備、規格頁、設定頁的色票、手機橫式。
