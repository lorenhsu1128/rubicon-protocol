# 近戰連擊與連繫技

近戰的多元化：招式圖、跨系統的取消與連接、方向派生、處決、防禦反擊。參考《機動戰士鋼彈 EXTREME VS》（方向派生、步驟取消）、《機戰傭兵6》（推進踢、蓄力斬、失衡與直擊補正）、《惡魔獵人》《魔兵驚天錄》（跳躍取消、空中連段、完美閃避）、《泰坦降臨 2》《隻狼》《潛龍諜影 崛起》（處決、彈刀），以及使用者提供的參考影片（滑行切入、把敵人壓在貨櫃上連打、連腿一起的迴旋斬、射擊與近戰無縫切換）。

## 定案（2026-10-27）

- **派生的方式**：方向派生（EXVS 式）。節奏派生（停頓、蓄力）不做。
- **處決**：做，設定可以關掉（關掉時長按近戰鍵＝一般近戰）。
- **一般敵人吃近戰會硬直**：是。Boss 不硬直；敵對 AC 只有很短的硬直（霸體）。
- **開發順序**：第 0 期地基 → 第 1 期 C（跨系統的連接）→ 第 2 期 A（方向派生）→ 第 3 期 E（處決）→ 第 4 期 F（防禦反擊）。撞牆（D）、節奏派生（B）、多人連攜技（G）、可自訂的連段（H）不在這次的範圍。
- 動作只改外觀與玩家這一側的手感；判定、傷害照房主算（多人以房主為準）。

## 現況（改版前）

- `data/parts.js` 每把近戰武器的 `combo` 是一條直線（2～5 段）；`MechEntity.fire` 在前一段過了 35% 時按下＝排入下一段（`melee.queued`），`updateMelee` 在這一段結束時接下一段，每段扣 EN（`enCost × (0.6＋mChain)`）。
- 取消只有一種：近戰過了 50% 按 QB 中斷（`move`）。
- 近戰中 `fire` 對非近戰武器一律回傳 false（不能開槍）。
- `takeDamage` 的近戰：擊退 `kb`、上挑 `lift`、`comboHits` 累積 3 下（或終結技）就讓一般敵人失衡。
- 失衡連攜：打出失衡的同一個人換不同種類的武器繼續打，直擊補正再 ×`LINK_K`（1.2）。
- 同步：快照的 `s.m`＝[槽位, 段號, 時間]；客機與動作片段（`MeleeAnim.clipFor(def, 段號)`）都以段號查招式。

## 第 0 期：地基

### 招式圖（`combo`＋`moves`）

- `combo` 照舊是預設連段（一條直線；HUD、機甲庫、理論火力都看它）；派生招式、衝刺斬、空中招式、處決放在另一個陣列 `moves`。**段號＝把 `combo` 與 `moves` 接起來的索引**（`meleeMove(d, i)`、`meleeAll(d)`），所以快照的 `s.m`、動作片段、客機照舊用段號。
- 招式之間以 `id` 互相參照（沒有 `id` 的 `combo` 招式用索引）；`meleeIdx(d, ref)` 把 id 或段號換成段號。
- 招式節點多的欄位：

| 欄位                                  | 意思                                                                                                                                |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `id`                                  | 招式的名稱（給 `next`／`start`／`dashMove`… 參照）                                                                                  |
| `next`                                | 下一招（id 或段號）；沒寫時：在預設連段裡＝下一個索引，`moves` 裡＝沒有；`end: true`＝連段的最後一招                                |
| `dirs`                                | 這一招中按「前／側／後＋近戰」接哪一招 `{ f, s, b }`（可選，目前的武器沒有用；沒寫時預設連段的中途按方向＝換到武器的 `start` 路線） |
| `stun`                                | 打中一般敵人的硬直秒數（沒寫：一般 0.32、終結技 0.6）                                                                               |
| `launch`                              | 上挑：打中後可以跳躍取消追上去（第 1 期）                                                                                           |
| `air`／`dive`                         | 空中招式（出招期間滯空）／下劈（後半往下砸、把目標砸回地面）                                                                        |
| `side`                                | 側滑：突進方向從目標方向轉開 `SIDE_ANG`（依按下的左右）                                                                             |
| `thrust`／`spin`／`slam`／`dashSlash` | 招式的種類（突刺、迴旋、砸、衝刺斬：判定與動作的預設片段）                                                                          |
| `exec`／`hits`                        | 處決招式／每一下的時間點（比例，第 3 期）                                                                                           |
| `clip`                                | 動作片段 id（沒寫時照 `DEFAULT_MAP` 的索引與招式種類）                                                                              |

- 武器另外的欄位：`start`＝方向派生的起手 `{ f, s, b }`、`dashMove`（衝刺斬）、`airMoves`（空中連段的第一招，之後照 `next`）、`exec`（處決招式）；都是 id。盾擊 `SHIELD_BASH`（`data/melee.js`）在 `parts.js` 載入時加進每把近戰武器與空手的 `moves`。

### 取消窗口

`melee.queued` 從布林改成「下一招的段號」（−1＝沒有）。這一招過了 `QUEUE_AT`（35%）之後按近戰：依按下那一格的方向（第 2 期，`meleeDir`）決定；接招一律經過同一個函式 `meleeNext(d, 段號, 方向)`（`dirs` → 預設連段中途的 `start` 路線 → `next`），所以 AI、客機、動作展示都走同一條路。起手招由 `MechEntity.meleeStartIdx` 決定（盾擊 → 突擊推進中的衝刺斬 → 空中的 `airMoves` → 方向派生的 `start` → 第 1 招；電腦一律第 1 招）。

### 被打的硬直

- 一般敵人被近戰打中：`hitStunT`＝招式的 `stun`；`updateAI` 開頭在硬直中只跑 `move`（不移動、不開火），之後照常。敵對 AC（`ace` 與具名 AC）只有 0.12 秒；Boss 與部位、目標物、建築不硬直。
- 只在房主／單機；外觀用現有的受擊動作（`hitAnim`），不用同步。

### 傷害遞減

同一個目標連續被近戰打（`comboHits`，1.2 秒內接著打才累積）：第 5 下起每下 ×0.92，最低 ×0.5（`COMBO_DECAY`）。避免左右手交替、取消接連段變成無限連。

### 連擊數

沿用既有的傷害數字：連續命中同一個目標時顯示「HIT ×n」（`game/juice.js` 的 `pushPopup`），不另外做連擊計數。

## 第 1 期（C）：跨系統的連接與取消

| 連接                   | 輸入                                 | 條件與效果                                                                                                                                     |
| ---------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 近戰 → 射擊            | 近戰中按另一隻手（或肩上）的射擊武器 | 這一招打中過、而且過了 50%：近戰中斷、立刻開火；目標在 20 m 內時這一發傷害 ×1.15（零距離射擊）。                                               |
| 射擊 → 近戰突進        | 對失衡中的鎖定目標按近戰             | 突進距離放寬到 3 倍（最遠 40 m，`LUNGE_K`）：從遠處一口氣貼上去，接著照一般連段。                                                              |
| 近戰 → QB → 近戰       | 打中後按 QB 取消，0.6 秒內再按近戰   | 從下一招接回連段（`melee.resume`），扣 EN；一個連段最多取消 2 次（`QB_RESUME_MAX`）。                                                          |
| 近戰 → 跳躍 → 空中連段 | 上挑（`launch`）打中後按跳躍         | 中斷近戰、往目標起跳；空中按近戰出空中招式（`airMoves`：空中斬 → 空中斬 → 下劈砸地），空中招式期間滯空，被上挑的敵人在空中受到近戰時延長滯空。 |
| 突擊推進 → 衝刺斬      | 突擊推進中按近戰                     | 出武器的衝刺斬（`dashMove`），傷害與衝擊依速度 ×1～1.35。                                                                                      |
| 左右手交替             | 一隻手的近戰中按另一隻手的近戰武器   | 過了 50% 時換手接另一隻手的連段（從第 1 招）；每次換手扣 EN，傷害遞減照算。                                                                    |

- 第 1 期先給每把近戰武器加上 `launch` 的上挑、`airMoves` 與 `dashMove`（動作片段用預設片段組合）；方向派生的上挑在第 2 期改成「後＋近戰」。
- AI：一般 AC 不用這些連接（照原本的直線連段）；之後視情況讓具名 AC 用衝刺斬。

## 第 2 期（A）：方向派生

- 方向＝近戰鍵按下那一格的移動輸入，相對於目標方向（沒有目標時相對機體正面）：輸入小於 0.3＝中立；往目標方向的分量 > 0.6＝前；< −0.6＝後；其他＝側（左右鏡像）。房主本來就收到客機的移動輸入，所以不用改協定。（2026-10-27 改成看按鍵本身的方向，見下方「方向派生看按鍵」。）
- 每把近戰武器 3～4 條路線，舉例：
  - **PB-033 脈衝刀**：中立 橫斬 → 逆斬 → 突刺；前 突刺連打（3 下）→ 踢開；側 側滑迴旋斬（同時繞到側面）；後 上挑（launch）。
  - **LS-70 光束大劍**：中立 斬 → 斬 → 迴旋斬 → 下劈；前 突進刺；側 橫掃大迴旋（範圍大）；後 斬上（launch）。
  - **CR-9 破碎爪**：中立 五連爪；前 抓住撕開（多段）；側 迴旋爪；後 上撈（launch）。
  - **PB-X 打樁機**：中立 撞擊 → 樁擊；前 衝刺樁擊（突進長）；後 上頂（launch）。打樁機的派生少、一下重。
  - **拳**：中立 直拳 → 勾拳 → 重擊；前 突進肘擊；側 迴旋踢；後 上勾拳（launch）。
- 動作片段：新的招式在 `melee-anim.js` 的 `TEMPLATES` 加預設片段（從現有的放大、鏡像、組合），`DEFAULT_MAP` 照索引對應；動作編輯器照舊可以改。

## 第 3 期（E）：處決

- **條件**：失衡中的敵人在近距離（處決招式的 reach＋`EXEC_R`＝3 m，舊尺度）、玩家按住近戰鍵 0.35 秒（`EXEC_HOLD`）。觸控與手把同樣是按住。設定 `ctrl.exec`（預設開）；關掉時按住只是一般近戰。
- **過程**：兩台機體對位（處決方移到目標正面、面向它），播處決動作（一般敵人約 1 秒、AC／精英 1.6 秒），期間雙方無敵、不能被打斷；鏡頭拉近（單人與自己的畫面）；最後一下造成大量傷害（一般敵人必定擊破，AC 與精英約 40% AP，Boss 不能處決）。
- **每把武器一種**：刀＝刺穿後拔出、大劍＝斬成兩半、爪＝撕開裝甲、打樁機＝頂住打穿、拳＝連打後重擊。
- **回報**：回復 AP 5%、EN 全滿、掉一個彈藥箱。
- **同步**：處決招式是 `moves` 裡的一招，段號照舊由快照的 `s.m` 帶給客機；被處決方在房主端是失衡＋面向處決方，客機照快照顯示。客機的輸入多一個 `nx`（自己關掉處決），`NET_VERSION` 改成 11.1。

## 第 4 期（F）：防禦反擊

- **彈刀**：敵人近戰的有效判定碰到玩家正在出手的近戰（雙方都在有效期間、面對面）時，雙方彈開；敵人硬直 1 秒（Boss 0.4 秒），接下來 1 秒內玩家的近戰必定打出失衡。
- **完美 QB**：敵人的攻擊（近戰、子彈、雷射、爆炸）命中前 0.15 秒內 QB 閃開：不受傷，單人時頓格 0.12 秒（多人不改遊戲時間，只給本人閃光、音效與「完美迴避」字樣），接下來 1.5 秒內第一下近戰的衝擊 ×2、突進距離 ×2。
- **盾擊**：裝 SH-02 脈衝盾時，擋下攻擊後 0.5 秒內按近戰＝盾擊（衝擊大、短距離）。觸控的攻擊鍵在這 0.5 秒內一律是近戰（平常依距離切換射擊與斬擊，遠處開槍的敵人就打不出盾擊）。
- 要有會近戰的敵人才有意義：一併讓近戰型 AC 與專屬敵人（鑽擊、實驗體、寄生體…）的近戰走同一套判定。

## 輸入的寬容（2026-10-27，試玩回饋：方向派生與接招的時機太嚴格）

- 改版前：這一招過了 35% 才收下一下（之前按的直接丟掉）、收招後按＝從第一招重來，所以接得上的時間只有 0.14～0.27 秒；方向只看按下近戰的那一格。
- 定案（使用者的選擇）：先行輸入＋收招後的寬限＋方向的寬容與角度放寬；連段中途按著方向就切換的規則不變；設定「近戰輸入輔助」寬鬆（預設）／標準；課程的難度曲線一起放寬。
- 數值（`data/melee.js` 的 `MELEE_ASSIST`，只給玩家操作的機體 `meleeA()`；電腦照舊 35% 才排入，敵人的行為不變）：

|                            | 先行輸入（這一招過了幾 % 就收下一下） | 收招後的寬限 | 方向的寬容（按下近戰前後） |
| -------------------------- | ------------------------------------- | ------------ | -------------------------- |
| 寬鬆（預設、近戰訓練一律） | 0%                                    | 0.35 秒      | 0.25 秒（已拿掉）          |
| 標準                       | 15%                                   | 0.2 秒       | 0.15 秒（已拿掉）          |

- 先行輸入：`fire` 的排入下一招看 `A.buf`。
- 收招後的寬限：收招時這一招之後還接得下去就記 `meleeGrace`（槽位、段號、剩下的時間），寬限內按近戰＝`meleeNext` 接下一招（照連段的 EN 消耗，不受收招的冷卻擋住）；取消、硬直（`meleeEnd`）清掉。
- 方向的寬容（`dirWin`：按下前後推過的方向也算）在下一節的改版拿掉了；前、後各 ±60° 保留。
- 設定 `ctrl.meleeAssist`（'easy'｜'std'，`#ctrlMeleeAssist`）：單機在 `player.js` 設 `p.mAssist`；多人時客機的輸入帶 `ma`（1＝標準），房主設在那台機體上（`NET_VERSION` 11.2）。

## 起手的方向派生（2026-10-27，試玩回饋：起手派生時機體先退開，很反直覺）

- 問題：有鎖定時機體一律面向目標，推「後」或「側」就是面向敵人倒退或側移，起手的派生得先推方向，機體已經先退開或側移。
- 第一版（A 按下近戰先預備 0.1 秒、B 近戰距離內方向按住 0.12 秒才移動、F 觸控在攻擊鍵上滑動）試玩後覺得更難操作（有時間頓點的判定），改成下一節。

## 方向派生看按鍵（2026-10-27，定案）

- 問題的根源是「方向相對目標」：俯視時同一顆 W 依敵人在畫面哪一邊而意思不同，推「後」本身就是叫機體走開。
- 定案（使用者選的）：**按下近戰（或接招）的那一格按著哪個方向鍵，就出哪一招**：上＝前、下＝後、左右＝側（各 ±60°，斜上／斜下算前／後；`data/melee.js` 的 `meleeKeyDir`），和目標在哪裡無關；招式照舊打向鎖定的目標。沒有時間窗：按下前放開的、按下後才推的都不算。拿掉第一版的 A、B 與方向的寬容（`dirWin`、`wishMem`、`meleeLateDir`），先行輸入與收招後的寬限保留。
- 方向是**輸入軸**（換成世界方向之前；機體相對移動與追尾／第一人稱時是機體或鏡頭的上下左右）：`input.js` 的 `meleeInKey(x, z)` → 實體的 `inKey`（`{ k, side, sw }`），單機在 `player.js` 每格設定（近戰訓練的示範從世界方向以 `tutAxes` 換回按鍵），`meleeDirKey()` 只讀它（只給玩家操作的機體）。側滑招式往目標的哪一邊繞看 `side`（右＝+1）。
- 多人：客機的輸入帶 `mk`（'' 中立、f、b、l／r 側，後面加 `!`＝觸控滑動），房主設成那台的 `inKey`（`NET_VERSION` 11.3）。
- 觸控在攻擊鍵上滑動（26 px）保留：滑動當成 4 格的方向鍵（`swipePulse`，`sw: true`），只給方向派生、不移動機體。因為點下去那一刻已經出了中立的第一招，滑完時 `meleeSwipeDir` 把還沒打中的中立起手改成方向起手、把沒帶方向的已排入下一招改成派生（只有滑動會這樣，按鍵與搖桿不會）。近戰訓練在觸控時不把中立起手算成「方向不對」。

## 反擊的提示與放寬（2026-10-27，試玩回饋：彈刀與完美 QB 的容許值太低）

- 定案：敵人攻擊前一定有明顯的提示，**看到提示之後按下去就成功**（不必抓準最後一瞬間）。
- **提示**（`MechEntity.atkCue(目標, 提示到出手的秒數, 出手後還算的秒數)`：記下 `cueN`／`cueTgt`／`cueUntil`，畫紅色閃光、紅圈、「!」、警報聲，都是會轉送給客機的 fx）：
  - 一般敵人（不是玩家操作的機體、不是 PvP、不是 Coral 戰爭）對玩家的近戰：先預備（當時 0.55 秒，之後改成 `CUE_LEAD`，見下一節，`m.cue`，`meleeCueTick`：停下來面向目標、紅光閃爍；被打中的硬直期間暫停、失衡或目標不見就取消），時間到才出刀；連段的後幾招也算在同一次提示裡（`startMeleeStage` 延長 `cueUntil`）。
  - 預警招式（`data/ai.js` 的 `MOVES`）：準備開始時提示，秒數照 `data/melee.js` 的 `CUE_POST`（[準備, 出手後還算的秒數]，包含子彈飛行）。
  - 近戰訓練的假人：照它自己的預警（0.9 秒，`tutTele` 以 `quiet` 只記狀態）。

## 打擊感改版（2026-10-28，使用者定案）

檢查後的問題：傷害在動作揮下去之前就算（判定從 10% 開始，動作出手在 30%～50%）、連段要等收招播完才接下一招、頓格不分輕重而且全場一起變慢、揮擊音每把武器都一樣、刀痕角度是亂數；派生招式大多借用一般連段的動作；敵人被打只有一種「往後仰一下」。定案：頓格**只停攻擊者與被打的敵人**、處決做被處決方的配對動作、照下面的順序一期一期做（每期測試後 commit／push）、**不同的派生要有不同的音效**。

### 第 1 期：打擊時機與手感

- **出手的時間點**：動作片段的 `hit`（比例），沒寫時＝蓄力的關鍵影格（緩動 in）到下一個關鍵影格之間的 55%（`melee-anim.js` 的 `clipStrike`；招式的 `hitAt` 優先，`MeleeAnim.strikeFor(def, 段號)`）。`startMeleeStage` 記在 `m.strike`，判定從 `strike − STRIKE_PRE`（0.06）開始到 85%。迴旋斬的片段 `hit` 0.2。
- **貼上目標就停**：判定變晚之後，近距離的突進會在揮下去之前穿過目標，所以一般招式離目標 `reach × 0.5` 以內就不再往前衝（突進追擊照舊 0.7，側滑不停）。
- **突進至少衝到出手**：突進的時間＝`max(拳 0.3／其他 0.6, strike＋0.03)`；距離照招式（`dash × 突進倍率`），每格離散少衝的部分在突進結束那一格補足（`m.dashGone`）。
- **近戰訓練的示範腳本**：完美 QB 與彈刀的按鍵時機對著假人提早出刀的秒數（`tl.so`）。
- **敵人近戰的「!」**：預備＝`lead −（出招到揮下去的秒數）`（最少 0.05 秒），「!」照舊在打到前 lead 秒；近戰訓練的假人在預警結束前同樣的秒數出刀（`D.tele.so`），所以刀照舊在預警結束時打到。
- **提早接下一招**（玩家）：打中過、排好下一招時，過了 `max(CHAIN_MIN 0.6, strike＋CHAIN_AFTER 0.24)` 就切進下一招，不等收招播完。
- **頓格只停攻擊者與目標**（`MechEntity.hitStopLocal(秒, 對方)`：`hsT` 期間 `move`／`remoteUpdate` 的時間 ×`HITSTOP_K` 0.06）。秒數依招式的重量（`data/melee.js` 的 `meleeWeight`：0 輕＝0.22 秒以下的招式、1 一般、2 終結技與打樁機、3 打樁機／大劍的終結技與處決的最後一下；`HITSTOP` [0.04, 0.065, 0.1, 0.15]）。彈刀、處決、打出失衡、QB 衝撞、擊破一般敵人、電腦受到重擊也改成局部；Boss 擊破、完美 QB 的慢動作照舊全場。客機：命中特效 `fx.meleeHit` 的第 5 個參數帶 `{ sw, s, r }`，`fx.onMeleeStop` → `meleeStopNear` 讓命中點 `r` 以內的機體一起停。
- **刀痕與鏡頭依揮的方向**（`meleeSwingOf`：t 突刺、s 迴旋、v 往下砸、u 上挑、h／hm 橫斬與反手）：刀痕的角度（上挑、下劈的刀痕往上／往下移動，突刺另有小衝擊環）；玩家打中時 `camPunch` 把鏡頭往那個方向推一下（`camKickTick`，三種視角都有），震動依重量。
- **音效依武器與派生**（`audio.js` 的 `meleeSwing(音色, 派生, 招式, 位置)`／`meleeHit(終結, 位置, 派生, 音色, 重量)`）：音色 blade／saber／claw／pile／fist；派生 `meleeCat(def, 段號)`＝n 預設連段、f 前派生（尖的突刺聲）、s 側派生（拉長的風切）、b 後派生（往上爬的音）、a 空中（推進器）、d 下劈（往下衝＋砸地）、x 衝刺斬（推進器爆發）、e 處決、h 盾擊；命中音另外依重量疊爆裂聲。
- 修正：近戰打到可破壞物件時 `meleeHit` 的參數順序寫反。
