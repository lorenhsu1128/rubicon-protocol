# 機甲動作改版

AC 機甲（人形機甲：二足、逆關節，部分適用四足與履帶）的動作改版。動作層是 `render/mech-model.js` 的 `animateMech`（程式算的姿勢，FK），之後疊 `render/mech-ik.js` 的 IK 修正層。

## 定案（2026-10-25）

- **風格**：動漫風格——快、俐落、姿勢幅度大、有過衝與回彈（不是 AC6 寫實的沉重感）。
- **地面移動三種**：滑行（高速時的主要移動）、跑步、走路，依速度切換。
- **分期**：
  1. 手感：彈簧取代 lerp、上下半身分離、滑行與起步／煞車、QB 依方向、起跳／空中／依下落速度的落地、原地轉身踏步。
  2. 戰鬥：依武器種類的射擊動作（輕／重後座、加特林、蓄力、架肩、換彈、肩上武器）、近戰改成關鍵影格（每把武器自己的招式），做成模型庫裡可以編輯的動作工具；同時處理手持武器的持握角度（武器穿插前臂），但以射擊爽度（槍口朝向、準星、開火手感）優先。
  3. 演出：受擊方向的反應、失衡依方向、擊破倒下、附加晃動（頭、背包、肩上武器）、待機與具名 AC 的個性。
- 動作只改外觀：碰撞、判定、子彈發射點的計算方式不變（發射點本來就跟著手，多人以房主為準）。

## 第一期（已實作）

### 彈簧（`render/mech-spring.js`）

- `spring(obj, key, to, w, z, dt)`：二階阻尼彈簧（角頻率 w、阻尼比 z），半隱式尤拉、每步最多 1/90 秒（RTS 的動作每 2～4 格才更新時 dt 比較大）。速度存在 WeakMap（以 `rotation`／`position` 物件為鍵），不寫進 userData。
- `springSet(heavy)`：依機體重量（0 輕～1 重，`MechEntity.animExtra` 由總重量換算）給各部位的參數：腿快、過衝小（腳要踩穩）；軀幹與手臂比較有彈性；近戰揮擊 `snap` 爆發、明顯過衝。
- IK 每格開頭把關節還原成動作層的結果（`ikRestore`），彈簧從那裡接著算，速度不受 IK 影響。
- 車庫展示姿勢、失衡傾倒、四足的腳步、載具照舊用 lerp。

### 移動狀態（`m.an`，每台模型一份）

- `animateMech` 的 `st` 多了 `vr`（水平速度÷機體速度）、`vy`、`dyaw`（這次更新之間的轉向）、`landV`（落地時的下落速度）、`heavy`，由 `MechEntity.animExtra()` 產生（`move` 與客機的 `remoteUpdate` 都傳；客機的落地由快照的 `grounded` 由假變真判斷）。
- **滑行**：`vr` 在 `GLIDE_ON`（0.8）以上維持 `GLIDE_DELAY`（0.3 秒）或地面 QB／突擊推進 → `an.glide`；降到 `GLIDE_OFF`（0.6）以下回到跑步。權重 `an.gW`：腳前後錯開、雙膝微彎、不踏步（`ikGait` 停住相位、沒有腳步聲；IK 的 `ctx.glide`：兩腳都是支撐腳、不鎖腳步）、上身前傾、手往外張往後掃、推進器 0.75。
- **跑步／走路**：`runK`＝(vr−0.4)/0.4：抬腳更高、擺臂更大、前傾；走路照原本的步伐。修正了原本抬腳時膝蓋往前反折（膝的旋轉負值才是正常彎曲）。
- **煞車**：速度比例每秒掉 1.5 以上（`an.dv`）→ `an.bW`：前腳撐住、後腳屈膝、上身後仰、手往前。
- **QB**：開始時記下方向（`an.qF` 前後、`an.qS` 側向）→ `an.qW`：前衝＝腿往後拖、上身前壓、手往後；後退＝腿往前、後仰；側衝＝前導腳往外張、另一腳收起、上身往移動方向傾。
- **起跳／空中／落地**：離地時往上的速度 > 2 ＝起跳（`an.jumpT` 前 0.14 秒伸直腿、腳尖往下）；上升時一腳收高一腳伸，下落時雙腳往前下伸；懸浮另一個姿勢。落地的蹲踞深度與長度依 `landV`（`an.landK`），重落地時手張開。IK 在空中（權重淡出的期間）不再把腳拉回地面（`st.stance` 0）。
- 加減速的前傾／後仰（`leanX`）在軀幹上多放大一次。

### 上下半身分離

- 下半身（`legsG`）朝移動方向轉（跑步上限 `LEG_YAW` 0.7、滑行 `LEG_YAW_GLIDE` 1.15 rad，往後移動時腿朝反方向＝倒退跑；履帶上限 90°），上半身（`torso`，掛在 `lift` 下、不在 `legsG` 裡）照舊朝機體正面（準星）。步伐與側步用腿的座標裡的移動方向計算。
- 原地轉向：下半身先留在地面上（反向轉回 `dyaw`），差超過 0.55 rad（履帶 1.3）時兩腳交替踏步轉過去（`an.align`）。
- 碰撞與判定不變；IK 的腳貼地、腳步鎖定以世界座標計算，不受影響。

### 檢查方式

- 渲染風格實驗室的「動作展示」（`game/lab-demo.js`，工具列的「動作展示」）：清掉兩隊、在空曠的地方（中心 42 m 內的地圖物件拿掉）由腳本操作玩家的機體，依序表演 28 段（待機、走路、跑步、滑行、煞車、側移、斜向、倒退、原地轉身、QB、跳躍、懸浮、5 種射擊、換彈、肩上武器、4 種近戰、受擊、失衡前後、檢查武器、擊破倒下）；左側清單點選、← → 換段、R 重播、連續播放、四個鏡頭角度、拖曳旋轉。新增動作時在 `DEMO_SEGS` 加一段。離開展示（回到觀看／操作）時重建戰場。冒煙測試 `testLabDemo`。

- 截圖腳本（不在版本庫）：玩家機體照腳本移動（取代 `updatePlayer`），地面改成平的、隱藏地圖物件與 HUD，側面固定鏡頭拍各狀態。

## 第二期（已實作）

### 持握角度

- 武器槽位的關節設定 `hold`（`weapon/<id>/<r|l>`，glTF 座標，以握點為中心）：`buildMech` 在 `weapon` 關節群組和武器之間多一層 `arms[k].aim`，手臂瞄準 IK 以它的 −Z 當槍管（扶槍也是），所以槍身往外擺、槍管照樣對準準星，前臂往外斜。
- 內建預設機甲（`src/assets/player-mech/joints.json`）的值：以四種手臂量前臂＋上臂的重疊體積挑的角度，最多 20°（射擊爽度優先）：SG-027 −20°／−3°、MG-014 −20°／−8°、LSG-06 −20°／−5°、LR-036 −18°／−4°、EMP-9 −14°、BZ-31 −17°、LS-70 −10°、RF-024 −7°／3°（偏航／俯仰，負的偏航＝槍口往內；左手偏航變號）。手和握把的重疊（拳頭握住握把）是正常的；CR-9 的套筒、刀劍的柄尾沒有處理。

### 依武器種類的射擊動作（`render/mech-fire.js`）

- `fireClass(def, back)`：light（步槍、手槍）、beam（雷射）、mg（射速 < 0.06 的連射）、heavy（霰彈）、shell（火箭筒、榴彈）、charge（蓄力雷射、電磁槍）；肩上：b_missile、b_light、b_gat、b_cannon（背雷射砲、榴彈砲、大型電磁脈衝）。`MechEntity.animWeapons()` 給 `st.wk`、蓄力進度 `st.ch`、換彈 `st.rl`（0→1→0）。
- 開火＝後座量（`st.recoil`）上升的那一格：手臂（肩上武器）上跳的彈簧 `m.an.kk` 給衝量、上身後仰（`kick`），重武器與連射撐住下盤（`an.brW`：屈膝、張腿、往前壓），連射時上身震動。手臂與肩上武器的上跳在 IK 瞄準之後才套用（`mech-ik.js` 讀 `rig.an.kk`），否則會被瞄準抵消；蓄力時舉槍、後仰；換彈時槍往下翻、瞄準放鬆。
- 榴彈槍開火補上後座量（以前沒有）。

### 近戰的關鍵影格（`render/melee-anim.js`）

- 片段 `{ name, keys: [{ t, e, p }] }`：t＝招式進度 0～1（招式長度與判定照武器資料，不受動作影響），e＝到這一格的緩動（io／out／in／lin／back／hold），p＝關節的值（度；壓低是公尺）。關節：上身扭轉、上身、下半身朝向、壓低、頭、左右上臂／前臂／手上武器、左右大腿／膝／腳掌。每個關節各自一條軌跡，沒寫的關節照程式算的姿勢。片段是為右手做的，左手武器左右鏡像。
- 預設片段 `TEMPLATES`（橫斬、逆斬、突刺、下劈、迴旋斬、大斬、爪、撞擊、樁擊、直拳、勾拳、重擊…）與武器的對應 `DEFAULT_MAP`；內建覆寫 `src/assets/anims/melee.json`（`{ v, clips, map }`）；單人時用模型庫動作編輯器存在瀏覽器的版本（localStorage `rubicon_melee_anim`，`lmRefresh` 重新讀；多人一律內建）。
- `animateMech`：`st.melee.clip` 有片段時，片段寫到的關節改用比較硬的彈簧 `SP.clip` 跟著片段（`CO`），扭轉 `an.tw`、壓低加到 crouch；迴旋斬轉完一圈換回 ±180° 以內。

### 動作編輯器（模型庫的「動作編輯」，`library/motion.js`，網址 `#motion`）

- 左：武器與連段（每一段選用哪個片段）、片段的複製／改名／還原、存到瀏覽器、匯出／匯入 melee.json、全部還原。中：目前模型組的機甲＋時間軸（播放、速度、關鍵影格的位置）、「遊戲中的樣子（彈簧）」＝從頭以 60 Hz 跑 `animateMech`，關掉＝直接套關鍵影格；「左手武器」看鏡像。右：關鍵影格（時間、緩動、新增、刪除）與各關節的拉桿。
- 修改的只是覆寫（沒改過的片段用預設）；預設片段第一次修改時複製。冒煙測試 `testMotion`。

## 第三期（已實作）

- **受擊**：`MechEntity.hitAnim(方向, 強度)`（`takeDamage` 呼叫；客機在 `pop` 事件以命中點推算）記下機體座標的推力方向，`st.hits` 給 `animateMech`：上身往被推的方向後仰／側傾、扭轉、背包與肩上武器的彈簧衝量；強度 0.85 以上時踉蹌一步（`an.stum`）。
- **失衡依方向**：最後一次受擊的 `knockF`（前面打＝正）／`knockX`：前面或側面打＝往後仰、屈膝撐住，背後打＝往前跪（一腳跪地），側傾往被推的那一側，手往外甩。修正了原本失衡時膝蓋往前反折。
- **擊破倒下**：人形機甲（二足、逆關節；不是 Coral 戰爭、過場動畫，`canCollapse`）擊破時先小爆炸、跪倒崩落 `COLLAPSE_T`（0.55 秒，`fx.collapse` 直接改關節、冒火花），之後才碎裂與擊破的爆炸（`fx.task` 的 `end`；`fx.clear` 時不呼叫）。客機的 `dieVisual` 一樣。
- **附加晃動**：背包（`rig.pack`）隨加減速、側向加速以慢的彈簧 `SP.sec` 晃動；受擊與 QB 開始時背包、肩上武器（`an.kk.bl／br`）給衝量。
- **待機**：一陣子（7～19 秒）沒動作時右手把槍舉到面前看一下（`an.relax.r`：手臂瞄準 IK 放鬆、`an.rh`：頭部注視放鬆）；電腦的機體依名稱固定的個性 `MechEntity.animPersonaOf()`：前傾、待機的重心晃動、轉頭的幅度與快慢。

## 第四期：動感（2026-10-26 定案）

參考影片（俯視約 60° 的機甲動作遊戲，30 秒之後的實機畫面）的觀察：高速滑行時整台從腳底往前倒 30～40°（腿也跟著斜，不是只彎腰）、溜冰式的寬站姿與低重心、轉彎往內側傾；QB 起步先縮一下再爆發、兩手甩開、結束時滑停揚塵；空中身體跟著飛行方向；近戰有明顯的蓄力、跨步突進（骨盆往前送）、連腿一起的全身迴旋、出刀後的跟隨與大的刀光；姿勢不對稱（一手出力一手平衡），頭、手、背包比軀幹晚一點到位；地面留下推進氣流的白線與腳印。

我們看起來「直直的」的原因：傾斜只在軀幹（腿永遠直立）、幅度約影片的一半、IK 的地形傾斜把整台的傾斜拉回垂直（往垂直拉 35%、最多 0.14 rad）、沒有預備動作與收招、各部位同時到位、近戰骨盆不動。俯視鏡頭下前後傾會被壓縮，左右傾、偏航、兩腳間距與兩手張開才讀得出來，所以左右的量要給多一點，截圖檢查用遊戲的鏡頭角度。

分期：

- **4a 手感（已實作）**：全身傾斜、轉彎傾斜、滑行姿勢與數值。
- **4b（已實作）**：QB 的預備 → 爆發（過衝）→ 滑停（`an.skid`）；空中姿勢跟著速度向量、上升收腿更高、空中跳的小幅翻轉；部位之間的先後（骨盆 → 胸 → 頭／手臂，目標加上上一層角速度 × 負係數）。
- **4c 近戰（已實作）**：預設片段幅度 ×1.4～1.6、蓄力停久一點（`hold`）、出刀 `out`；片段加 `root` 通道（骨盆往前／側的位移＝跨步突進，只是外觀）；迴旋斬連 `legsG` 一起轉（腳的 IK 淡出）；`snap` 阻尼降到約 0.3 做出跟隨；頓格時凍結彈簧速度；刀光沿武器 GLB 的 `tip` 節點畫帶狀弧線。動作編輯器與 melee.json 的格式一併改（加版本）。
- **4d 特效（已實作）**：滑行／QB 的地面推進氣流帶、煞車／滑停／落地的腳印、揚塵；殘影（選用）留到之後。

姿勢準則：不要左右對稱（一手出力一手平衡、一腳承重一腳放鬆）；每個動作都有「預備 → 動作 → 收招」，預備的方向和動作相反；剪影優先（俯視時兩腳的間距、兩手的張開、刀伸出去的距離要一眼看得出來）。

### 4a（已實作）

- **全身傾斜**（`animateMech` 的 `an.root`）：二足、逆關節的 `lift` 繞自己的原點（＝地面、兩腳中間）轉，整台連腿一起倒向移動方向：滑行 `ROOT_GLIDE`（0.32 rad × 速度比例，側滑時 0.8 倍往側面）、跑步 0.06、QB 前衝 `ROOT_QB`（0.26，後退＝後仰）、煞車後仰 0.14；上限 `ROOT_MAX`（0.42）；彈簧 `SP.root`（比軀幹慢，整台的質量）。軀幹的前傾（tX）照舊疊在上面，所以滑行合計約 30°。近戰、失衡時歸零。IK 每格開頭 `ikRestore` 把 `lift` 還原成單位四元數，動作層每格重新設定，所以不會累積；腳的 IK 把腳拉回地面（腿變斜、膝彎更多），伸不到時照舊壓低骨盆。
- **IK 的地形傾斜**（`mech-ik.js` 的 lowerBody 2.）：二足／四足改成以世界的垂直為起點，只加「垂直 → 坡度」那一段，不再把整台的傾斜（mesh 的 leanX／leanZ、上面的全身傾斜）拉回垂直；履帶照舊整個貼齊地面。
- **轉彎傾斜**：整台的 mesh 已依側向加速度（含轉彎的向心加速度）傾 `leanZ`；全身傾斜再加 `leanZ × ROOT_BANK`（0.8，空中一半），滑行時另有 1.6 Hz 的重心左右移動。腳踝的側傾補償（`ftRoll`）把全身傾斜的側傾也算進去。
- **滑行姿勢**：兩腳前後錯開 0.5／−0.45（原本 0.3／−0.26）、膝 −0.55／−0.25、腳掌 0.1／0.35、外展 0.22（原本 0.1），壓低 0.11（原本 0.05）；手臂不對稱：和前腳（右）同側的手往後掃 0.5、另一手往前 0.18（溜冰的平衡），外展 0.3。
- **QB**：壓低 0.08、手臂外展 +0.35＋0.3×qW；開始時兩手往外甩（上臂 z 的彈簧衝量 ±3.5）。

### 4b（已實作）

- **QB 三段**：開始的 `QB_ANT`（0.06 秒）是預備（`an.qAnt`，權重 `antW` 0→1→0）：壓低 0.09、全身往 QB 的反方向傾 0.16（前後）／0.14（側）；預備結束才開始爆發：`an.qW` 改成二階彈簧（`an.qq`，ω 30、阻尼 0.42，過衝到約 1.2，上限 1.3），結束時 ω 13、阻尼 0.85。QB 結束時在地面上有 `SKID_T`（0.32 秒）的滑停（`an.skid`，權重 `skW` 1→0）：全身往回仰（同預備的方向），往前或往側衝之後的滑停用煞車的姿勢（`an.bW` 至少 skW × (qF＋0.5)）。QB、預備、滑停時全身傾斜的彈簧加快（ω × (1＋1.6 × 權重)）。
- **空中**：全身傾斜在空中跟著水平速度（`ROOT_AIR` 0.2，側向 0.8 倍）；上升時低的那隻腳也收起（大腿 0.45、膝 −0.8，高的 1.05／−1.4）。
