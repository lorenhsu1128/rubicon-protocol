# 文字動畫 APNG 產生器 — 功能規格

參考對象：「文字画像APNGメーカー」（kumachansteps.github.io/trpg-web-tools/tools/text-apng-maker/）。

> 該網站的利用規則明文禁止「本工具本身或其主要部分的無斷複製、再發布、轉載」，且原始碼未附開源授權。
> 因此本專案**只參考功能（做什麼）**，程式碼、文案、模板、圖示、配色皆為獨立撰寫（clean-room），不複製原站任何檔案內容。

## 0. 技術前提
- 純前端靜態網站（HTML + CSS + 原生 ES Modules），不需建置工具，可直接部署到 GitHub Pages 等靜態空間。
- 所有影像處理都在瀏覽器內完成，不上傳伺服器。
- APNG 用瀏覽器內建 `CompressionStream('deflate')` 壓縮，自行組 PNG/APNG chunk；不依賴外部函式庫。
- WebP 用 `canvas.toBlob('image/webp')` 逐格壓縮後組成動畫 WebP（VP8X + ANIM + ANMF）。

## 1. 三種模式
| 模式 | 用途 | 特點 |
|---|---|---|
| 訊息 message | 「戰鬥開始」等切入演出 | 主文字＋副文字；登場→顯示→退場 |
| 預告 trailer | 較長的文章演出 | 逐字/逐行/捲動等「顯示流程」；空行分頁 |
| 地點・時間 caption | 探索地點、場景字幕 | 同訊息引擎，預設配置在畫面角落 |

## 2. 模板
- 每種模式有一組模板，一鍵套用字型、顏色、動畫、裝飾、輸出循環方式。
- 訊息模式的模板分類：戰鬥／探索・事件／GM／場景・時間／檢定（檢定再分規則系統）。切換分類時自動選第一個模板。
- 新世紀福音戰士（EVA）風格模板分散在戰鬥、探索・事件、場景・時間分類，標籤以「EVA・」開頭（作戰開始、A.T. 力場、暴走、使徒襲來、第一種戰鬥配置、圖形：藍、MAGI 決議、同步率、活動限界、標題卡、次回預告、恭喜）；只有文字演出，不含標誌圖形。
- 訊息與預告：使用者改寫的文字依模板分別記憶；地點・時間：切換模板時保留文字。
- 「重設」把當前模式恢復初始狀態（需確認）。
- 模板決定輸出循環預設值（一般為播放一次；GM、檢定類與部分持續顯示的模板，例如 EVA 的系統畫面，為無限循環）。

## 3. 設定分頁
### 文字
主文字（預告模式為多行正文）、副文字＋位置（上/下）、書寫方向（橫/直）、對齊（左/中/右）、
自動換行字數（預告）、空行分頁（預告）、超出時自動縮小（並提示縮小前後的字級）。
### 字型
字型挑選器（分類、卡片預覽、懶載入）、粗細、斜體、文字色、字級、字距、行距；
副文字的字型/粗細/斜體/顏色/大小比例/字距/與主文字間距；
上傳自己的字型（TTF/OTF/WOFF/WOFF2，存在 IndexedDB，下次可用，按兩下 × 移除）；指定電腦已安裝字型名稱。
### 動態
- 預告模式「顯示流程」：逐字、中央逐字、從中央向兩側展開、逐行、流暢掃過、整體同時、捲動，以及各自參數
  （速度、單字顯現時間、標點停頓、換行停頓、行間隔、掃過時間、捲動速度、邊緣淡化、打字游標、頁間空白等）。
- 登場（可關閉）：效果卡片＋滑鼠移上去的小預覽。方向、時長、逐字延遲、順序（開頭/結尾/中央/兩端/隨機）、緩動曲線、強度。
  登場效果：淡入、浮現、落下、上下匯合、滑入、字距收攏、從中央展開、模糊變清晰、彈出、由大縮小、旋轉、翻轉、落下彈跳、聚合、打字機、明滅、重擊、逼近、從深處浮現、擦除、展開、故障、閃光。
- 顯示中：顯示時長、效果（無、飄浮、波浪、心跳、顫抖、光暈明滅、忽明忽暗、閃爍、間歇故障）、強度；提示「加動作會讓檔案變大」。
- 退場（可關閉）：不消失、淡出、向上消失、下沉、上下分離、滑出、字距散開、模糊、膨脹消失、縮小消失、飛散、逐字消除、明滅、逼近消失、遠去、擦除、收起、故障。
- 時機：副文字登場方式、副文字相對主文字的時差、開始前空白、結束後空白、總時長提示。
### 裝飾
樣式預設（一鍵配色）、填色（單色/漸層＋方向＋漸層預設）、填色不透明度、描邊、外描邊、陰影、外發光、故障色、副文字顏色、游標顏色；
裝飾：無、色帶、警戒膠帶、方框、標題框、上下線、底線、兩側線、強調條、角框，以及顏色、濃度、線寬、線條描邊、膠帶寬度/速度/閃爍、留白、延伸長度、邊緣柔化、兩端淡化、圓角、裝飾動畫（伸展/淡入/無）與時長。
### 背景・配置
整張背景：無（透明）、純色、暗角、底部漸層、頂部漸層，濃度、隨文字淡入淡出；
圖像尺寸（預設尺寸＋自訂寬高）；九宮格基準位置、左右/上下邊距、水平/垂直微調。

## 4. 預覽
- Canvas 即時預覽；預覽背景：透明格紋/黑/白/灰/自選圖片（圖片只用於預覽）。
- 播放/暫停、從頭開始、循環播放、登場開關、退場開關（捲動模式時停用並說明）。
- 時間軸可拖曳，顯示登場/顯示/退場區段顏色；時間顯示。
- 預覽與輸出的畫面必須完全一致（所有隨機都由時間與索引決定）。

## 5. 輸出
- FPS：12/15/20/24/30/60；循環：播放一次（停在最後）/無限/指定次數；色數：256 色/全彩。
- 檔名依文字與動畫自動填入（無登場/無退場/循環會加註），手動改寫後可「恢復自動」。
- 不支援 APNG 的環境顯示完成狀態的靜態圖（預設影像不參與動畫）。
- 自動裁切透明邊距。
- 輸出 APNG、WebP、PNG 靜態圖（播放中＝完成狀態，暫停＝當下畫面）、PNG 序列（ZIP）。
- 批次輸出：每行一段文字（`主文字|副文字`），同一設計輸出並打包 ZIP（上限 30 段）。
- 進度條、中止、結果預覽（大小、尺寸、影格數、實際儲存張數、色數、循環），超過 5MB 時提示減量方法。
- APNG 最佳化：只存與上一格不同的矩形、相同影格合併延長、256 色時用全域調色盤（PLTE + tRNS）。

## 6. 其他
- 介面語言切換（繁中 / English，架構可擴充）、淺色/深色主題。
- 使用說明、使用規則、快捷鍵抽屜。
- 快捷鍵：Esc、Ctrl/Cmd/Alt+Shift+P（播放）、E（輸出 APNG）、K（PNG 靜態圖）、1/2/3（切換模式）、T（主題）。
- 設定存在 localStorage（依模式分開），使用者字型存在 IndexedDB。
- 分享到 X 按鈕、手機版版面。
