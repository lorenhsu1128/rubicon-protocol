# 駕駛員畫面的操作介面

駕駛員畫面（`state` 'pilot'，`game/pilot-ui.js`）的改版：原本是 30 張文字卡片（每張兩個 ± 按鈕）、5 列預設組表單與一串熟練度文字，改成遊戲式的技能樹畫面。配點規則、存檔格式不變（`data/skills.js`、`data/pilot.js`）。

提案頁的四個方向：A OS 調校清單（機戰傭兵 6）、B 六角放射盤（FFX 晶球盤）、C 圖示節點樹（Diablo IV、Borderlands 3、The Division 2）、D 駕駛員檔案的子分頁外框。

## 定案（使用者的選擇，2026-10-27）

1. **技能樹用 C 圖示節點樹**：6 個直欄（分支），每個技能一顆圓形圖示，由上往下 T1、T2、T3，用線連起來；門檻是橫跨的虛線列。
2. **不要 D 的子分頁**：預設組與武器熟練度留在同一個畫面的右側欄。
3. **按住投點**：按住 0.45 秒投一點（進度圈），繼續按住每 0.45 秒再投一點；右鍵／X 退一點。
4. **顯示機體數值的變化**：右側欄的「機體數值」以目前的機體算出沒有配點、目前配點、投點之後三種數值。

## 畫面

```text
┌ 駕駛員 [PvE|PvP] (Lv 圈) 經驗條……               技能點 13 / 19 [全部重置][返回機甲庫] ┐
│ ┌ 射擊 6 ┬ 近戰 0 ┬ 機動 5 ┬ 能源 0 ┬ 裝甲 3 ┬ 支援 0 ┐  ┌ 機體數值 ─────────┐ │
│ │ ◎ ◎   │ ◎ ◎   │ …                         │  │ 六角（分支點數）     │ │
│ │ ‥3/3‥ │ ‥0/3‥ │   ← T2 的門檻              │  │ 火力 ▬▬▬ 312 +6%   │ │
│ │ ◎ ◎   │ ◎ ◎   │                           │  │ AP  ▬▬▬ …           │ │
│ │ ‥6/7‥ │ ‥0/7‥ │   ← T3 的門檻              │  │ 其他效果：…         │ │
│ │  ◉    │  ◉    │                           │  ├ 配置預設組（5 張卡）┤ │
│ └────────────────────────────────┘  ├ 武器熟練度（徽章）  ┤ │
│ [圖示 快速裝填 T1 ■■□  換彈時間 −12% → −18%  [按住投點][退一點]]        └──────────┘ │
└──────────────────────────────────────────────────────────┘
```

- **上方列**（`#pilotHead`）：PvE／PvP（`data-padtabs`）、等級圈與經驗條（`#pLevel`）、技能點（`#pPtsLeft`）、全部重置（`uiConfirm`）、返回。
- **技能樹**（`#pTree`）：一個格子，欄＝分支（標題：圖示、名稱、已投點數），列＝T1、T2 門檻、T2、T3 門檻、T3。節點 `button.pNode[data-skill]`：技能圖示（`render/pilot-icons.js`，依效果）、外圈分段的弧＝級數、下方「r／max」；狀態 locked（前置不足：變暗、鎖）、can（可以投點：外圈呼吸）、on、max（金色）；T3 較大、金框。門檻列每欄一格虛線＋「3／3 ✓」。節點之間的連線（T1→T2、T2→T3，T3 的前置技能那一條加粗）畫在 `#pLinks` SVG，排版後量節點位置（`pilotLinks`，視窗大小改變時重畫）。
- **詳細列**（`#pInfo`）：游標停留／焦點／最後點選的技能：圖示、名稱、分支與階層、級數格、效果「目前 → 下一級」（只寫數字，變動的數字綠色；`desc` 的文字拆成數字）、鎖住的原因、「按住投點」按鈕（觸控用，同樣按住）與「退一點」。
- **機體數值**（`#pStats`）：機體的六角性能圖（`#pHex`，和機甲庫規格頁同一套 `hexScores`：火力、裝甲、機動、EN、穩定、射程；灰＝沒有配點的機體（不透明，蓋在上面）、露出來的黃色帶＝配點的加成（黃色外框＝加點後的機體總能力）、虛線＝再投一點之後，每軸標出數值與配點的增加比例；2026-10-27 依回饋從「分支點數」改成機體數值）；數值列（持續火力、瞬間火力、AP、有效 AP、姿態穩定、地面速度、QB 速度、QB 消耗、跳躍高度、EN 容量、EN 回復、回復延遲、鎖定距離）：條的灰色＝沒有配點、黃色＝配點的加成、綠色＝投點之後再多的；文字＝目前的值與加成比例，預覽時「→ 新的值」，會變的列標亮。不影響這些數值的技能（擴散、追蹤、近戰範圍、修補包…）列在「其他效果」。武器熟練度照目前裝備的武器算（和出擊時一樣）。
- **配置預設組**（`#pPresets`）：5 張卡（`.pPreset`）：有內容的＝編號、名稱、左右手的武器圖示、配點數與那組機體＋配點的小六角性能圖，點卡片＝載入（`.pLoad`），卡上的「覆蓋」（`.pSave`）與「×」（`.pClr`，`uiConfirm`）；名稱點一下改（`.pName` 輸入框）；空的＝「＋ 儲存目前的機體」（`.pSave`）。
- **武器熟練度**（`#pProf`）：擁有的武器各一個徽章（`.pProfRow`）：武器圖示＋熟練度圈（滿級金色）＋5 顆星＋下一級的加成一行。

## 操作

- 滑鼠：游標停留＝詳細列；按住左鍵＝投點（重複）；右鍵＝退一點；點一下＝選取（詳細列固定在它）。
- 觸控：點一下＝選取；按住節點或詳細列的「按住投點」＝投點；「退一點」按鈕。
- 手把：十字鍵移動焦點（節點依畫面位置），按住 A＝投點（`pad-ui.js`：焦點元素有 `padHold` 時，A 不 click，而是把按住的狀態交給它），X＝退一點（`padDec`），LB／RB＝PvE／PvP，B＝返回。
- 投點時節點閃一下＋介面音；點數用完或達上限時按住沒有反應（進度圈不跑）。

## 版面

- 電腦 1920×1080：技能樹在左、右側欄 380 px。
- 平板 1180×820：同一個版面，右側欄 320 px。
- 手機橫式 844×390（`max-height: 540px`）：上方列一行、節點 40 px、詳細列縮短；右側欄移到技能樹下方（整個畫面捲動）。
