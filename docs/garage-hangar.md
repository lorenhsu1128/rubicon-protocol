# 機甲庫的格納庫演出

機甲庫（`state` 'garage'）正中央的機體改成站在格納庫的整備架上，換零件、維修、出擊都有對應的演出（參考鋼彈的格納庫、機戰傭兵6 的組裝畫面、MechWarrior 5 的機庫）。

## 定案（使用者的選擇）

1. **風格：混合**。瀏覽零件時是機戰傭兵6 式的數位全像（快、不擋操作），確定換上時是鋼彈格納庫式的實體換裝（吊車、機械臂、火花）。
2. **換裝的長度：約 2 秒**（可以略過；連續換時直接快轉到最新的）。
3. **固定在整備架上**：機體不再自轉，改成鏡頭繞著看（拖曳旋轉、滾輪縮放、停手後慢慢回到預設角度）。
4. **技師與車輛：要，簡單的人偶**（帶出尺寸感：機體 3.24 m、人 1.7 m）。
5. **維修：每次進機甲庫都看得到**：依目前狀態顯示受損，技師與無人機補修，修好後消失。
6. **出擊演出：要**（整備架鬆開、升降台或彈射軌道，接到原本的出擊流程）。
7. **場景依場合不同**：

| 場合（`campGarageUi` 的 mode） | 場景 |
|---|---|
| free（自由出擊）、lv（自訂關卡） | 基地格納庫：高天花板、兩側鷹架、天花板吊車、武器架、遠處停著其他機體的剪影 |
| hub（主線的作戰室） | 委託方運輸艦的格納庫：矮天花板、金屬牆與肋材、舷窗外的雲海、警示燈 |
| trans（主線的轉場整備） | 前線的野戰整備區：帆布帳篷、照明燈塔、補給車、沙包、夜空 |
| mp（多人） | 大型格納庫：多個整備位，隊友的機體站在旁邊的整備架上 |

## 分期

### 第一期：場景、鏡頭、全像預覽、掃描換裝（已完成）

- `render/hangar.js`：四種場景的建造（純函式，程式模型；靜態的部分依材質合併），會動的部分（吊車、燈、技師、無人機、蒸氣）由 `tickHangar(h, dt, t)` 驅動。
- 整備架：機體背後的支架、兩側的鷹架與走道、肩高的固定臂。
- 鏡頭（`game/hangar.js` 的 mixin）：拖曳繞看、滾輪縮放、停手 4 秒後慢慢回到預設；選部位時轉到那個部位的鏡頭位置（頭、手臂、腳、背包、肩上武器…）。
- 技師人偶：走動、站著看平板、電焊（火花）、指揮；搬運車來回。
- **全像預覽（瀏覽）**：滑鼠停在零件清單的項目上（手把的焦點也算）時，在機體上疊一個「換上這個零件」的全像（青色、掃描線、半透明），只顯示會變的區塊，原本的區塊變暗。
- **掃描換裝**：換上零件時，比較新舊兩台機甲的區塊（`rig.pieces` 的槽位 id），只有變了的區塊播放：一條光帶由下往上掃過，光帶下方是新零件、上方是舊零件（材質的 clippingPlanes），0.5 秒。第二期起改成只在「簡短」設定時使用。
- 設定「整備演出」：完整／簡短／關閉（`ctrl.hangarFx`）。冒煙測試（`?test`）預設簡短。

### 第二期：實體換裝（已完成）

- 依部位的換裝流程（2.1 秒，`game/hangar.js` 的 `RT` 時間表）：鏡頭轉到看得到零件去向的位置 → 夾具接近（0～0.45）→ 夾住（火花、鏗聲）→ 舊零件移走（0.5～1.0）→ 新零件送來（1.1～1.65）→ 鎖上（火花、蒸氣、重鏗聲）→ 夾具收回（1.8～2.1）→ 鏡頭回到部位的位置。整備架肩高的固定臂全程伸過來扶住機體。
  - 頭、肩上武器：天花板吊車（吊鉤到零件頂上，零件往上吊 3 m）。野戰帳篷沒有吊車，改用機械臂。
  - 手持武器、手臂：機械臂從地板下升起（底座的開口），夾住零件往外前方拉出，沉進旁邊地板的開口；手臂兩側同時換時兩支機械臂一起動。
  - 核心、推進器：往後拉 2.4 m，沉進背後地板的開口。
  - 腳部：整備位的地板開口，舊的腳沉下去、新的腳升上來；新的腳到位之前，上半身維持在舊的高度（機體根節點的位移）。
- 只換一類零件時才播實體換裝；同時換好幾類（隨機組裝）或設定「簡短」時用第一期的掃描。播放中又換了零件：目前的流程直接完成，接著播新的。點一下畫面（`#garageMid`）略過。
- 地板的開口（`render/hangar.js` 的 `makeHatch`）：兩片門滑開，下面是一片黑色的面；沉下去的零件被地板擋住，所以看起來是掉進開口。
- 零件的位移：記下零件在父節點（關節群組）裡的原位 `p0`，每格以世界座標的位移 `hangarRigPath` 換算回父節點的區域座標（機體照常跑待機動作）。

### 第三期：維修、出擊、多人

- 維修：進機甲庫時依狀態顯示受損（主線轉場整備依 AP 比例；其他場合依上一次出擊的損傷，沒有時是輕微的整備），電焊無人機與技師補修，補彈藥車接上武器，修復套件的箱子送進背包。
- 出擊演出：整備架鬆開 → 升降台把機體送上去（基地）、彈射軌道（運輸艦）、走出帳篷（野戰）→ 接原本的出擊／空降轉場。
- 多人：隊友的機體站在旁邊的整備架上（依大廳的組裝）。

## 實作備註

- `this.garageMech` 仍是目前的機體（冒煙測試會讀它的 `modelSrc`）；換裝期間舊的機體另外放在 `this.hg.swap.old`，只顯示被換掉的區塊。
- 區塊比對：`rig.pieces` 以槽位 id 為鍵（`head/h_std`、`weapon/w_mg/r`…），新的有、舊的沒有＝換上的區塊。
- 剪裁：`renderer.localClippingEnabled` 在機甲庫開著；剪裁時區塊的材質換成複本（同一台機甲的區塊共用材質），描邊外殼暫時隱藏，結束後還原。

## 第一期的實作

- `render/hangar.js`：`buildHangar(kind)` 回傳 `H`（`root`、`beds`（整備架；`clamps` 是肩高的固定臂）、`workers`、`cars`、`cranes`、`beacons`、`sparks`、`light`＝背景色／霧／陽光／半球光）。不會動的部分以 `P`／`gBox` 收集後 `bakeStatic` 依材質合併、不畫描邊；只有整備架、人偶、車輛投影。加色的特效（全像、掃描帶、火花、警示燈）用 `keepAlpha`（不改 alpha，後處理以 alpha 分辨機體與環境）。
- 技師的工作清單 `[種類, 位置, …]`：walk（走過去）、look（看著機體）、tab（看平板）、weld（電焊：`['weld', 位置, 焊接點, 秒]`，焊接點在下方時蹲下）；走道上的直接定位。座標避開機體與整備架、不擋正面的鏡頭。
- `game/hangar.js`：`hangarKind()`（mp→multi、轉場整備→field、作戰室→ship、其他→base）、`hangarEnsure()`（換場合時重建、改燈光與霧）、`hangarOpen()`（`openGarage` 呼叫：進來時不播換裝）、`hangarTick(dt, t)`（主迴圈的 garage 分支：機體、預覽、換裝中的舊機體的動作，以及場景、全像、換裝、鏡頭）。
- 鏡頭：`hg.cam` 往 `hg.goal` 平滑移動（yaw／pitch／dist／tgt）；`#garageMid` 接收拖曳（單指旋轉、雙指縮放）與滾輪；`hangarView(slot)` 依部位取機體節點的位置；`setViewOffset` 讓機體在左右面板中間。
- 全像：`#partList .part` 帶 `data-pid`，每格看滑鼠停留（`:hover`）或手把焦點（`.padFocus`），停 0.12 秒後建一台換上那個零件的機體，只顯示新的區塊、材質換成 `HOLO`；目前機體被換掉的區塊換成半透明的材質複本，清除時還原。
- 換裝：`renderGarage` 以 `hgAsm`（組裝的 JSON）判斷組裝變了沒，變了就把舊的機體留在場景、呼叫 `hangarSwapStart(舊, 新)`；兩台都先跑 60 格動作讓姿勢一致。又換了零件時 `hangarFinish` 先結束上一個。
- 冒煙測試 `testHangar`。
