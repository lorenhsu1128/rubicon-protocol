# Rubicon Paint

直接在 GLB 模型上繪製貼圖的編輯器，給 [RUBICON PROTOCOL](https://github.com/lorenhsu1128/rubicon-protocol) 的機甲用。純靜態網頁：用瀏覽器直接開 `index.html`（file:// 也可以）就能用，不需要伺服器或建置。

- three.js 固定 r128（`lib/three/`），和 rubicon-protocol 相同版本、相同的全域 `THREE` 寫法，方便之後併進模型庫。
- 桌機（滑鼠、繪圖板）與平板（筆、觸控）都可以用；繪圖板的壓感、筆的橡皮擦端都支援。
- 介面依瀏覽器視窗大小自動縮放（以 1400×850 為 100%，70%～160%，觸控裝置最小 85%）；右上角「介面」選單可以改成固定比例。

## 功能

**繪圖**
- 在 3D 上直接畫，跨過 UV 接縫的線條是連續的、不會變形（在 UV 空間跑投影繪圖）。
- 筆、橡皮擦、滴管、填色（UV 島／整個材質）、漸層（目前顏色 → 透明）。
- 13 種筆刷預設：G筆、圓筆、鉛筆、噴槍、水彩、麥克筆、粉筆、噴霧、方頭、星星、閃光、愛心、花。
- 筆尖圖形、紙紋（紙、帆布）、散佈、大小抖動、角度隨機／沿筆畫方向；壓感影響尺寸／不透明度；手震修正。
- 「背面也畫」：筆刷變成 3D 球體，連背面、被擋住的面一起畫。
- 「左右對稱」：以模型中心的 X 鏡像。
- UV 面板也可以畫（預設跨接縫連續，依 3D 位置接著畫；也可以只在貼圖平面上畫）、填色、取色。

**貼上圖片**：按「圖片」、把圖片拖進視窗或 Ctrl+V 貼上，在模型上點一下就像貼紙一樣貼上去（沿表面法線投影）；之後可以拖曳移動、調大小、角度、不透明度，按 Enter 確定。

**圖層**：每組貼圖（每張貼圖）有自己的圖層，最下面是原貼圖的「底圖」。
- 19 種混合模式、不透明度、隱藏、鎖定透明、剪裁遮色片。
- 新增、複製、上移、下移、向下合併、清除、刪除、雙擊改名。
- 所有繪圖與圖層操作都可以復原（Ctrl+Z／Ctrl+Y）。

**零件**：個別隱藏網格（H 隱藏游標下的零件、Alt+H 全部顯示），隱藏的零件不會擋住、也不會被畫到，用來畫被遮住的地方。

**AO 烘焙**：從多個方向計算凹處的陰影，加成每組最上面的「AO」圖層（色彩增值）。

**檔案**
- 開啟 GLB（也支援 Draco 壓縮）；有貼圖變換、沒有 UV、蒙皮網格會提示。
- 專案檔 `.rpaint`：原始 GLB＋所有圖層，Ctrl+S 儲存。每 5 分鐘自動暫存到這個瀏覽器，下次開啟可以「還原自動暫存」。
- 匯出：PNG（目前貼圖組；全部貼圖組存成一個 zip）、PSD（含圖層與混合模式）、GLB（貼圖換成畫好的結果，隱藏的零件也會匯出）。
- 存檔與匯出都會跳出「另存新檔」視窗選位置與檔名（Chrome、Edge）；不支援的瀏覽器（例如 Firefox）會直接下載到瀏覽器的下載資料夾。

## 操作

| 操作 | 滑鼠 | 平板 |
|---|---|---|
| 畫 | 左鍵 | 筆 |
| 旋轉視角 | 右鍵拖曳 | 單指 |
| 平移 | Shift＋右鍵、中鍵 | 雙指 |
| 縮放 | 滾輪 | 雙指捏合 |

| 鍵 | 功能 |
|---|---|
| B／E／I／G／U | 筆／橡皮擦／滴管／填色／漸層 |
| Alt（按住） | 暫時切成滴管 |
| [ ] | 筆刷大小（貼圖片時是圖片大小） |
| , . | 貼圖片的角度（Shift 每次 15°） |
| Ctrl+Z／Ctrl+Y | 復原／重做 |
| Ctrl+S | 儲存專案 |
| F | 全部顯示 |
| 數字鍵 1／3／7／5 | 正面／右／上／透視與平行切換（Ctrl＋1／3：背面／左） |
| H／Alt+H | 隱藏游標下的零件／全部顯示 |
| Enter／Esc | 貼圖片：確定／取消 |

## 已知限制

- UV 重疊的部位（例如左右對稱共用 UV）會一起被畫到。
- UV 超出 0–1、會重複貼的部分畫不到；貼圖變換（KHR_texture_transform）不處理。
- 蒙皮網格以靜止姿勢繪製。
- 遊戲的色槽材質是「陣營色 × 貼圖」，在色槽材質上畫彩色會被陣營色染色。

## 檔案結構

- `index.html`、`css/app.css`
- `js/paint-core.js`：繪圖核心（UV 空間投影繪圖、筆畫緩衝、圖層合成與接縫外擴、復原、填色、漸層、貼圖片、AO）
- `js/app.js`：介面、相機、輸入、檔案
- `js/brushes.js`：筆尖、紙紋、筆刷預設（都用程式產生）
- `js/fileio.js`：zip（專案檔）與 PSD 輸出
- `js/demo-model.js`：範例模型
- `lib/three/`：three.js r128 與 examples（GLTFLoader、GLTFExporter、OrbitControls、DRACOLoader）
- `lib/draco/`：Draco 解碼器（包成字串，第一次讀到 Draco 壓縮的 GLB 才載入）
